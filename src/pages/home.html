From your first C++ program to Codeforces 1600.

A short path with a fixed order. Each lesson takes 10–15 minutes to read. Then you practice. Hard words have a dotted line: point at them to see the Arabic meaning.

How to use this guide

  1. Go in order. Each lesson uses the lessons before it.
  2. Read, then solve. After each lesson, solve the problems in its practice ladder. Reading alone does not work.
  3. Think 20–40 minutes before you open a solution. Then write the code yourself, without looking.
  4. Mark it done and move on. Do not wait until you feel perfect.

Each lesson explains one idea in three ways: a story, a picture, and code. Use the one that works for you.
