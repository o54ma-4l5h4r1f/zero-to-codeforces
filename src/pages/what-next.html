The map

Three good places to learn. The table says where to look for each topic.

  • CPA = cp-algorithms.com — short text and code for almost every algorithm.
  • USACO = USACO Guide — lessons in order (Silver, Gold, Platinum) with chosen problems.
  • EDU = Codeforces EDU — free video lessons with practice problems.
TopicWhat it solvesWhere to learn
Segment treeSum / min / max of a range when the array also changes. O(log n) for each operation.EDU "Segment Tree" · CPA: Data Structures
Fenwick tree (BIT)Prefix sums with updates. Less power than a segment tree, but only 10 lines of code.CPA: Data Structures · USACO Gold
Sparse tableMin / max / gcd of a range in O(1) when the array never changes.CPA: Data Structures
Bitmask DPDP where the state is a set of items, for n ≤ 20. See Bits and Dynamic programming.USACO Gold · AtCoder DP contest (task O)
DP on treesThe best answer for each subtree, built from the children. See Trees.USACO Gold · AtCoder DP contest (task P)
LCA / binary liftingThe lowest common ancestor of two vertices in a tree. Gives the distance between any two vertices in O(log n).CPA: Graphs · USACO Platinum
Minimum spanning tree (Kruskal)The cheapest set of edges that connects all vertices. Sort the edges, then use DSU.EDU "Disjoint Sets Union" · USACO Gold
Bellman-Ford / Floyd-WarshallShortest paths with negative edges / between all pairs when n ≤ 500. See Dijkstra first.CPA: Graphs · USACO Gold
String hashingCompare two substrings in O(1): turn each one into a number.CPA: String Processing · USACO Gold
KMP / Z-functionFind a pattern inside a long text in O(n). Find borders and periods of a string.CPA: String Processing
Sqrt tricksCut the array into blocks of size √n. Each query costs about √n steps. Easy to code.CPA: Data Structures ("Sqrt Decomposition")
Game theory basicsTwo players play perfectly: who wins? Winning and losing positions, the game of Nim.CPA: Game Theory · CSES book, chapter 25

Do not learn this list from top to bottom. Segment tree and bitmask DP are the two you will meet first.

How to keep growing

  • From now on, contests and upsolving matter more than new topics. Most 1600–1900 problems need a good idea, not a new algorithm.
  • After every contest, solve the first problem you could not solve. This one habit gives the most rating.
  • Practice problems 100–300 above your rating. Think for 30–60 minutes before you open the editorial.
  • When a topic comes back again and again in editorials, that is the time to learn it. Then solve 5–10 problems on it.
  • Fast and correct on easy problems is half of your rating. Keep doing virtual contests.

Problem sets
