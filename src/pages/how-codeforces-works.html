Codeforces gives you problems. You send code. A judge runs it on hidden tests and answers in a few seconds.

Before this lesson

  • You need only basic C++: variables, if, loops, cin and cout.

Two places to solve

PlaceWhat it isUse it for
ProblemsetAll old problems. No timer. You can filter by rating and topic.Daily practice.
ContestsA contest has 5–8 new problems and lasts about 2 hours.Testing yourself. Your rating changes here.

Problems in a contest have letters: A, B, C, D… A is the easiest. Each next letter is harder.

A name like 4A means contest 4, problem A. A problem rating like 800 shows how hard it is. 800 is the easiest.

What the judge tells you

The answer of the judge is called a verdict. "Wrong answer on test 3" means tests 1 and 2 passed. Test 3 is the first one that failed.

VerdictWhat it meansWhat to do first
AcceptedAll tests passed.Go to the next problem.
Wrong answer (WA)Your program printed a wrong output.Read the statement again. Test small special inputs.
Time limit exceeded (TLE)Your program is too slow, or it never stops. Your idea does too many steps. You learn to count them soon.
Memory limit exceeded (MLE)Your program uses too much memory.Check the size of your arrays.
Runtime error (RE)Your program crashed.Look for an index outside the array or a division by zero.
Compilation error (CE)The code does not compile.Click the verdict to read the error. Check the language you chose.

In a contest you may see Pretests passed. Pretests are only the first part of the tests. The full tests run after the contest.

Solve one together

Problem. Get your first Accepted. The problem is 4A, "Watermelon". A watermelon weighs w kilos, with \( 1 \le w \le 100 \). Can you cut it into two parts, each with an even weight above 0? Print YES or NO.

  1. Make an account. Open codeforces.com. Click Register at the top right. Pick a handle and confirm your e-mail.
  2. Open the problem. Click Problemset in the top menu. Find problem 4A, or click it in "Your first problem" at the end of this page.
  3. Solve it by hand. \( w = 8 \): 2 + 6 works, so YES. \( w = 7 \): an odd weight never splits into two even parts, so NO. \( w = 2 \): only 1 + 1, and 1 is odd, so NO. The answer is YES only if w is even and bigger than 2.
  4. Write and test the code on your computer. Run it with the sample input 8. It must print YES. The next lessons show how to read a statement and how to run your code.
  5. Submit, click by click.
    1. On the problem page, click Submit Code in the menu above the problem.
    2. Check that the field Problem says 4A.
    3. In Language, choose a name that starts with GNU G++17, G++20 or G++23.
    4. Paste your code into the big box. Click Submit.
  6. Read the verdict. The site opens your submissions. You see "In queue", then "Running on test 2", then the verdict. If you see the green word Accepted, you passed all tests.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int w;
    cin >> w;
    if (w % 2 == 0 && w > 2) cout << "YES\n";   // even, and not 2
    else cout << "NO\n";
}

Wrong ideas people get

  • You may think: "Pretests passed" means my solution is correct for sure.

    The truth: It is only part of the tests. After the contest more tests run, and your code can still fail.

  • You may think: I must wait until I am ready before I join any contest.

    The truth: Join a Div. 4 or Div. 3 contest in your first week. A low first rating does no harm. It only shows where you start.

  • You may think: My code passes the sample, so it gets Accepted.

    The truth: The sample is one small test. The hidden tests are bigger and harder. The sample only catches the first bugs.

Common mistakes

  • You print extra text like "Enter n:". The judge wants only the answer.
  • You choose a wrong language, like C or Java, for C++ code. You get Compilation error.
  • You start with Div. 2 problem D. Start with A and B.

Check yourself

  1. The judge says "Wrong answer on test 5". How many tests did your code pass?
    Answer

    4. Tests 1 to 4 passed. Test 5 is the first one that failed.

  2. Your rating is 1450. Which of these changes your rating: Div. 4, Div. 3 or Div. 1?
    Answer

    Only Div. 3, because 1450 is below 1600. Div. 4 is rated only below 1400. Div. 1 is for 1900 and more.

  3. Which rank is the goal of this guide, and what rating is it?
    Answer

    Expert, blue, from 1600 to 1899.
