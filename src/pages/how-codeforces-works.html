Codeforces gives you problems. You send code. A judge runs it on hidden tests and answers in a few seconds.

Start in 10 minutes

  1. Open codeforces.com and press Register. Pick a handle (your name on the site).
  2. Open Problemset and find problem Watermelon.
  3. Write the code on your computer. Test it with the samples.
  4. Press Submit. Choose the language GNU G++17 or a newer one (G++20, G++23). Paste your code.
  5. Watch My submissions. You want the green word Accepted.

Two places to solve

PlaceWhat it isUse it for
ProblemsetAll old problems. No timer. You can filter by rating and topic.Daily practice.
ContestsA contest has 5–8 new problems and lasts about 2 hours.Testing yourself. Your rating changes here.

Problems in a contest have letters: A, B, C, D… A is the easiest. Each next letter is harder.

A problem name like 4A means contest 4, problem A. A problem rating like 800 shows how hard it is. 800 is the easiest.

Which contests to join

Each contest has a division. It shows the level.

ContestLevelFor you now?
Div. 4The easiestYes. Start here.
Div. 3EasyYes.

Div. 2MediumYes, after a few contests. Problem A is still easy.

You must register for a contest before it starts. The button is on the Contests page.

What the judge tells you

The answer of the judge is called a verdict. "Wrong answer on test 3" means tests 1 and 2 passed.

VerdictWhat it meansWhat to do first
AcceptedAll tests passed.Go to the next problem.
Wrong answer (WA)Your program printed a wrong output.Read the statement again. Test small special inputs.
Time limit exceeded (TLE)Your program is too slow, or it never stops.Count your steps from the limits. See Limits → speed.
Memory limit exceeded (MLE)Your program uses too much memory.Check the size of your arrays.
Runtime error (RE)Your program crashed.Look for an index outside the array or a division by zero.
Compilation error (CE)The code does not compile.Click the verdict to read the error. Check the language you chose.

More help for each verdict: How to find your bug.

Common mistakes

  • You submit without running the samples on your computer first.
  • You print extra text like "Enter n:". The judge wants only the answer.
  • You start with Div. 2 problem D. Start with A and B.
  • You are afraid to lose rating, so you do not join contests. Join them. See How to practice.
