C++ gives you ready tools: sort, max, sum, pairs. Learn their names and never write them by hand again.

Spot it

  • You need the numbers in order, or the k biggest, or the k smallest.
  • You need the biggest, the smallest or the sum of an array.
  • Two values belong together, like a score and the person who has it.
  • You are about to write 10 lines for something very common. Stop. There is a tool for it.

Three ways to understand it

1 · Story — the toolbox

A carpenter does not make a new hammer for every nail. He opens the toolbox and takes one.

The STL is the toolbox of C++. The tools are fast, correct and tested by millions of people. Your own sort will be slower and can have bugs.

2 · Picture — "I want… → write…"

Here a is a vector<int>.

I want…write…
sort, small → big (ascending)sort(a.begin(), a.end());
sort, big → small (descending)sort(a.rbegin(), a.rend());
or sort(a.begin(), a.end(), greater<int>());
turn the array aroundreverse(a.begin(), a.end());
smaller / bigger of two valuesmin(x, y) / max(x, y)
exchange two valuesswap(x, y);
smallest / biggest in the array*min_element(a.begin(), a.end())
*max_element(a.begin(), a.end())
sum of the arrayaccumulate(a.begin(), a.end(), 0LL)
how many times is x in the array?count(a.begin(), a.end(), x)
add a value at the enda.push_back(x);
look at the last value / remove ita.back() / a.pop_back();
two values in one boxpair<int,int> p = {3, 7};
p.first is 3, p.second is 7
an array of pairsvector<pair<int,int>> v; v.push_back({x, y});

The * is needed: max_element gives the place of the biggest value, and * opens it. 0LL makes the sum a long long; with plain 0 a big sum can overflow.

A pair is sorted by .first. If two firsts are equal, the smaller .second comes first.

before sort{5, 1}{2, 2}{5, 0}{1, 3}
after sort{1, 3}{2, 2}{5, 0}{5, 1}

3 · Code — the tools in one program

Read n scores. Print the smallest, the biggest and the sum. Then print the people from the best score to the worst.


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int smallest = *min_element(a.begin(), a.end());
    int biggest  = *max_element(a.begin(), a.end());
    long long sum = accumulate(a.begin(), a.end(), 0LL);
    cout << smallest << " " << biggest << " " << sum << "\n";

    vector<pair<int,int>> people;            // {score, number of the person}
    for (int i = 0; i < n; i++) people.push_back({a[i], i + 1});
    sort(people.rbegin(), people.rend());    // biggest score first
    for (int i = 0; i < n; i++) cout << people[i].second << " ";
    cout << "\n";
}

Input 4 / 30 10 50 20 prints 10 50 110 and then 3 1 4 2. Sorting moves the scores, but each pair still remembers its person.

Speed: sort is O(n log n), fine for n = 10^6. The other tools in the table are O(n) or O(1).

Common mistakes

  • a.size() is unsigned: it cannot be negative. For an empty array a.size() - 1 is a huge number, not −1. Write (int)a.size() - 1.
  • accumulate(…, 0) adds in int. Write 0LL.
  • You forget the * before max_element. The code does not compile, with a long error.
  • a.back(), a.pop_back() or *max_element on an empty array. The program crashes. Check !a.empty() first.
