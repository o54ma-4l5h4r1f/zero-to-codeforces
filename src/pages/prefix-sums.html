Add the numbers once and save every running sum. After that, the sum of any part of the array is one subtraction.

Spot it

  • Many queries: "what is the sum from position l to position r?"
  • "How many good positions are there between l and r?" Put 1 on good positions, 0 on others. Now it is a sum.
  • The array does not change between the queries.
  • n and the number of queries are both up to 200 000. A loop for every query is too slow.

Three ways to understand it

1 · Story — the bank balance

Every day you get or spend some money. The bank writes your balance after each day. This is a running sum.

How much did you get from Monday to Friday? You do not add five days again. You take the balance after Friday minus the balance before Monday.

2 · Picture — pre[i] = sum of the first i elements

The array a has indexes 0 … n−1. The array pre has one more box. pre[0] = 0 because the sum of zero elements is 0.

Each box is the box before it plus one element: pre[i + 1] = pre[i] + a[i].

One query: the sum of a[1..3] = 1 + 4 + 1 = 6.

The rule: sum of a[l..r] = pre[r + 1] − pre[l]. Take everything up to r, then remove everything before l.

3 · Code — build once, answer each query in one step


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> a(n), pre(n + 1, 0);       // sums get big -> long long
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        pre[i + 1] = pre[i] + a[i];              // sum of the first i + 1 elements
    }
    while (q--) {
        int l, r;
        cin >> l >> r;                           // the input counts from 1
        l--; r--;                                // now they are indexes from 0
        cout << pre[r + 1] - pre[l] << "\n";     // sum of a[l..r]
    }
}

It also works for counting. "How many i in [l, r] have s[i] == s[i + 1]?" Make a[i] = 1 when this is true, else 0. Then ask for a sum.

A grid (2D). pre[i][j] = sum of the first i rows and first j columns: pre[i][j] = a[i−1][j−1] + pre[i−1][j] + pre[i][j−1] − pre[i−1][j−1]. Sum of rows r1..r2 and columns c1..c2 = pre[r2+1][c2+1] − pre[r1][c2+1] − pre[r2+1][c1] + pre[r1][c1].

Difference array

This is the same idea, but backwards. Now the task says: "add v to every element from l to r", many times. At the end you print the array.

Example — 5 zeros, add 2 to [1, 3], then add 3 to [2, 4]

Do not touch every element of the range. Write only two marks in a difference array d: "the change starts here" (d[l] += v) and "the change stops here" (d[r + 1] −= v).

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;                               // the array starts with n zeros
    vector<long long> d(n + 1, 0);               // one extra box for d[r + 1]
    while (q--) {
        int l, r;
        long long v;
        cin >> l >> r >> v;                      // indexes from 0, add v to a[l..r]
        d[l] += v;                               // the change starts at l
        d[r + 1] -= v;                           // the change stops after r
    }
    long long cur = 0;
    for (int i = 0; i < n; i++) {
        cur += d[i];                             // running sum of d
        cout << cur << " ";                      // this is a[i]
    }
    cout << "\n";
}

Speed: O(n) to build, then O(1) for each query. Difference array: O(1) for each change, O(n) once at the end.

Common mistakes

  • Off by one. Choose one rule and never mix: here pre has n + 1 boxes and the answer is pre[r + 1] − pre[l].
  • The sums in an int. 200 000 numbers of 109 give 2·1014. Use long long.
  • The input counts positions from 1 and your array counts from 0. Subtract 1 from l and r first.
  • The array changes between queries. Then prefix sums are not enough. (You need a stronger tool, see After 1600.)
