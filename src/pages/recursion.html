A function that calls itself on a smaller problem. With it you can try every choice: take or skip, this order or that order.

Spot it

  • n is very small: n ≤ 20 means "try all subsets" (220 ≈ 106). n ≤ 10 means "try all orders" (10! ≈ 3.6 · 106).
  • For every item you make a choice: take it or skip it, plus or minus, group A or group B.
  • The statement says "print all…" or "count all ways…" and the numbers are tiny.
  • The problem contains a smaller copy of itself, like n! = n × (n−1)!.

Three ways to understand it

1 · Story — the line of people

You stand in a long line. You want to know your position, but you cannot see the front.

You ask the person in front of you: "What is your position?" He does not know, so he asks the next person. This goes on until the first person. She says "I am 1". This is the base case: no more questions.

Now the answers come back: 2, 3, 4… Each person adds 1 to the answer he gets. Every recursion has these two parts: a base case that stops, and a step that asks a smaller question.

2 · Picture — all subsets of {1, 2, 3}

Look at the numbers one by one. For each number choose: take it (go left) or skip it (go right). After 3 choices you reach the bottom. Each bottom point is one subset.

This drawing is the call tree. 3 choices → 2 × 2 × 2 = 8 subsets. With n numbers the bottom has 2n points.

3 · Code — take or skip

Count the subsets with sum exactly target. The function go(i, sum) means: "numbers 0..i−1 are decided, their sum is sum".


#include <bits/stdc++.h>
using namespace std;

int n;
long long target;
vector<long long> a;
int ways = 0;

void go(int i, long long sum) {
    if (i == n) {                  // base case: every number is decided
        if (sum == target) ways++;
        return;
    }
    go(i + 1, sum + a[i]);         // choice 1: take a[i]
    go(i + 1, sum);                // choice 2: skip a[i]
}

int main() {
    cin >> n >> target;
    a.resize(n);
    for (auto &x : a) cin >> x;
    go(0, 0);
    cout << ways << "\n";
}

Input 3 3 and 1 2 3 prints 2: the subsets {1, 2} and {3}.

Backtracking: try, go deeper, undo

Sometimes you need the chosen items themselves, not only their sum. Keep them in one vector. Add an item, go deeper, then remove it before the next choice. This is backtracking.


int n;
vector<int> a, chosen;

void go(int i) {
    if (i == n) {                        // base case: print this subset
        for (int x : chosen) cout << x << " ";
        cout << "\n";
        return;
    }
    chosen.push_back(a[i]);              // try: take a[i]
    go(i + 1);                           // go deeper
    chosen.pop_back();                   // undo
    go(i + 1);                           // now try without a[i]
}

Two short forms without recursion. Subsets: a loop over bit masks. Orders: next_permutation (sort first!).


for (int mask = 0; mask < (1 << n); mask++) {     // every subset
    long long sum = 0;
    for (int i = 0; i < n; i++)
        if (mask >> i & 1) sum += a[i];          // bit i is 1 -> a[i] is taken
}
sort(p.begin(), p.end());
do { /* use the order p */ } while (next_permutation(p.begin(), p.end()));

Stop early when a branch cannot win. Example: the sum is already bigger than the target and all numbers are positive → return. This makes backtracking much faster.

Speed: subsets O(2^n) → fine for n ≤ 20. Orders O(n!) → fine for n ≤ 10. Always check n before you start.

Common mistakes

  • No base case, or a base case that is never reached. The function calls itself forever and the program crashes.
  • The next call is not smaller: you write go(i) and not go(i + 1).
  • You forget to undo. After push_back and the call, you must pop_back.
  • n is too big. For n = 40, 240 is about 1012: too slow. Look for DP or greedy.
