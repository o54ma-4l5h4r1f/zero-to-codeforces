C++ has ready boxes for your data. Pick the right box and a hard problem becomes a few lines.

Spot it

  • "Did I see this value before?" or "how many distinct values?" → set.
  • "How many times does each name / number appear?" and the values are big or are strings → map.
  • You add values and often need the smallest or biggest one → priority_queue or multiset.
  • Brackets, "undo", or "the last thing that is still open" → stack.

Three ways to understand it

1 · Story — four things from real life

A stack is a pile of plates. You put a plate on top. You take a plate from the top. Last in, first out.

A queue is a line in a shop. New people stand at the back. The person at the front leaves first. First in, first out.

A set is a guest list. Each name is there one time only, and the list stays in order. A map is a phone book. You give a name (the key) and you get a number (the value).

3 · Code — brackets with a stack, then short examples


#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;                              // for example ([]{})
    stack<char> st;
    bool good = true;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);                    // opening bracket: remember it
        } else {
            if (st.empty()) { good = false; break; }   // nothing to close
            char open = st.top();
            st.pop();
            if (c == ')' && open != '(') good = false;
            if (c == ']' && open != '[') good = false;
            if (c == '}' && open != '{') good = false;
        }
    }
    if (!st.empty()) good = false;         // some bracket was never closed
    cout << (good ? "YES" : "NO") << "\n";
}

set: unique and sorted.


set<int> s;
s.insert(5); s.insert(2); s.insert(5);     // s = {2, 5}, the second 5 is ignored
if (s.count(5)) cout << "5 is inside\n";
cout << s.size() << "\n";                  // 2 = number of distinct values
cout << *s.begin() << "\n";                // 2 = the smallest value
auto it = s.lower_bound(3);                // first value >= 3
if (it != s.end()) cout << *it << "\n";    // 5

map: count words, then print them in order.


map<string, int> cnt;
string w;
while (cin >> w) cnt[w]++;                 // a new key starts at 0
for (auto [word, times] : cnt)             // keys come in sorted order
    cout << word << " " << times << "\n";

priority_queue: the biggest on top, or the smallest on top.


priority_queue<int> big;                               // max on top
priority_queue<int, vector<int>, greater<int>> small;  // min on top
for (int x : {4, 9, 1}) { big.push(x); small.push(x); }
cout << big.top() << " " << small.top() << "\n";       // 9 1
big.pop();                                             // removes the 9

Speed: set, map, multiset, priority_queue: O(log n) per operation. stack, queue, deque: O(1). So n operations cost O(n log n) or O(n).

Common mistakes

  • m[x] creates the key x with value 0 if it is missing. To only check, use m.count(x).
  • In a multiset, s.erase(x) removes all copies of x. For one copy write s.erase(s.find(x)).
  • top(), front() or pop() on an empty container crashes. Check !st.empty() first.
  • lower_bound(s.begin(), s.end(), x) on a set is slow, O(n). Use the member: s.lower_bound(x).
