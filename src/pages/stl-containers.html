C++ has a ready box for each kind of question. Pick the right box, and a hard problem becomes a few lines.

Before this lesson

  • You can use vector, pair and sort → STL basics
  • You can read \( O(\log n) \) and \( O(1) \) → Limits → speed

Spot it

  • "Did I see this value before?" or "how many distinct values?" → set.
  • "How many times does each name or number appear?" → map.
  • You add and remove values, and you often need the smallest or the biggest → multiset.
  • Brackets, "undo", or "the last thing that is still open" → stack.

Three ways to understand it

1 · Story — four things from real life

A stack is a pile of plates. You put a plate on top. You take a plate from the top. Last in, first out.

A queue is a line in a shop. New people stand at the back. The person at the front leaves first. First in, first out.

A set is a guest list: each name once, always in order. A map is a phone book. You give a name, the key, and you get its number, the value.

2 · Picture — which box do I need?

Each row is one situation. The second column is the ONE box to use first. \( n \) is the number of values in the box.

\( O(\log n) \) is small: for \( n = 2 \cdot 10^5 \) it is about 18 steps.

Now watch a stack check the brackets of ([]{}). An opening bracket goes on the stack. A closing bracket must match the top.

3 · Code — the bracket check, then set and map


#include <bits/stdc++.h>
using namespace std;

char openOf(char c) {                      // the opening bracket that fits c
    if (c == ')') return '(';
    if (c == ']') return '[';
    return '{';
}

int main() {
    string s;
    cin >> s;                              // for example ([]{})
    stack<char> st;
    bool good = true;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{')
            st.push(c);                    // opening bracket: remember it
        else if (st.empty() || st.top() != openOf(c))
            good = false;                  // nothing open, or the wrong kind
        else st.pop();                     // it fits: this pair is closed
    }
    if (!st.empty()) good = false;         // some bracket was never closed
    cout << (good ? "YES" : "NO") << "\n";
}

set: each value once, sorted.


set<int> s;
s.insert(5); s.insert(2); s.insert(5);     // s = {2, 5}, the second 5 is ignored
if (s.count(5)) cout << "5 is inside\n";
cout << s.size() << "\n";                  // 2 = number of distinct values
cout << *s.begin() << "\n";                // 2 = the smallest value

map: count words, then print them in sorted order.


map<string, int> cnt;
string w;
while (cin >> w) cnt[w]++;                 // read words until the input ends
for (auto [word, times] : cnt)             // keys come in sorted order
    cout << word << " " << times << "\n";

A new key starts at 0, so cnt[w]++ works for a word seen for the first time. Each element of a map is a pair: the key, then the value. auto [word, times] gives the two parts names. So word is the key (.first) and times is the value (.second). auto lets C++ write the type for you. More: C++ reference, part "pair and tuple".

s.begin() is not a value. It is the place of the first value, an iterator. * opens the place. A search that finds nothing gives s.end(), the place after the last value. That is all you need now.

Which one do I use? Use map, not unordered_map. On Codeforces, special tests can make unordered_map very slow.

Solve one together

Problem. A bag starts empty. There are \( q \) commands. + x puts the number \( x \) in the bag. - x takes one copy of \( x \) out. ? prints the smallest and the biggest number in the bag. Limits: \( 1 \le q \le 2 \cdot 10^5 \) and \( 1 \le x \le 10^9 \). The commands are always possible.

  1. What is asked? After each ?, the smallest and the biggest value in the bag.
  2. A small example by hand.
    command+ 5+ 2+ 5?- 5?- 2?
    bag after52 52 5 52 5 52 52 555
    print2 52 55 5

    The value 5 is in the bag twice. - 5 takes out only one of them.

  3. The idea. Go down the table in the picture. We need duplicates, removal of any value, the smallest and the biggest. That row says multiset. To remove only one copy, write bag.erase(bag.find(x)). Plain bag.erase(x) removes every copy. The smallest value is *bag.begin(). The biggest is *bag.rbegin(): the "r" means "from the right end".
  4. Why is it fast enough? Each command costs \( O(\log q) \), about 18 steps. All commands: \( 2 \cdot 10^5 \cdot 18 \approx 3.6 \cdot 10^6 \) steps. That is far below \( 10^8 \).

#include <bits/stdc++.h>
using namespace std;

int main() {
    int q;
    cin >> q;
    multiset<int> bag;                     // sorted, duplicates allowed
    while (q--) {
        char type;
        cin >> type;
        if (type == '+') {
            int x;
            cin >> x;
            bag.insert(x);
        } else if (type == '-') {
            int x;
            cin >> x;
            bag.erase(bag.find(x));        // removes ONE copy of x
        } else {
            cout << *bag.begin() << " " << *bag.rbegin() << "\n";
        }
    }
}

Speed: set, map, multiset: \( O(\log n) \) per operation. stack, queue: \( O(1) \). So \( n \) operations cost \( O(n \log n) \) or \( O(n) \).

Wrong ideas people get

  • You may think: A set keeps the values in the order I inserted them.

    The truth: A set keeps them sorted, small to big. The insert order is lost. Need the input order? Keep a vector too.

  • You may think: Reading m[x] does not change the map.

    The truth: If x is missing, m[x] adds it with value 0. Then m.size() grows. To only check, write m.count(x).

  • You may think: In a multiset, s.erase(x) removes one copy of x.

    The truth: It removes all copies. For one copy, write s.erase(s.find(x)).

Common mistakes

  • top(), front() or pop() on an empty container. The program may crash or give garbage. Check !st.empty() first.
  • *s.begin() on an empty set. It reads garbage. Check !s.empty() first.
  • s.find(x) when x is not there gives s.end(). Erasing s.end() is an error: it may crash or break the set. Be sure x is inside.

Check yourself

  1. You must print every different word once, in alphabetical order. Which box do you use?
    Answer

    set<string>. It keeps each word once, and a loop gives them sorted.

  2. A multiset holds 1 3 3 7. What is left after s.erase(3)?
    Answer

    1 7. Plain erase(3) removes both copies of 3.

  3. An empty stack: push(1), push(2), pop(), push(3). What is on top? How many values are inside?
    Answer

    3 is on top. Two values are inside: 1 and 3. The pop() removed the 2.
