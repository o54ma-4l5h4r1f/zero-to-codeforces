When the answer is too big for any type, keep only its remainder. Take the remainder after every \( + \) and \( \times \), and the numbers stay small.

Before this lesson

  • You know %, the remainder of a division → Basic math
  • You know that long long holds up to about \( 9 \cdot 10^{18} \) → int or long long?
  • You can write 13 as 1101 in binary, and b / 2 drops its last bit → Bits

Spot it

  • "Print the answer modulo \( 10^9 + 7 \)" (or 998244353). Both are used the same way: same code, other number.
  • You count the number of ways, and it grows very fast.
  • You need \( a^b \) with a huge \( b \), like \( b = 10^{18} \). That is fast power.
  • "The last digit of …" is the same idea, modulo 10.

Three ways to understand it

1 · Story — the clock

It is 10 o'clock. What time is it after 5 hours? Not 15. The clock shows 3.

We write \( 15 \bmod 12 = 3 \). In C++ it is 15 % 12. You can add the hours one by one, or all together. The clock shows the same time.

Why does the judge ask for a remainder? The real answer can have thousands of digits. The remainder by \( 10^9 + 7 \) fits in an int. It still shows that your method is right.

2 · Picture — what is safe, on small numbers

Take \( m = 10 \). The remainder by 10 is the last digit. Compare "mod at the end" with "mod first".

mod at the endmod first, then againsame?
17 + 2542 → 27 + 5 = 12 → 2yes
17 · 25425 → 57 · 5 = 35 → 5yes
30 / 6, with \( m = 7 \)5 → 52 / 6 → 0no

With \( + \) and \( \times \) you may take the remainder at any moment. The result does not change. With division you may not. Division needs another tool. See "Not now".

Negative numbers. On a clock with 5 numbers, walk 7 steps back from 0. You stop at 3. But C++ prints something else:


cout << -7 % 5;                // prints -2, not 3
cout << ((-7 % 5) + 5) % 5;    // prints 3: add m, then take % again

3 · Code — fast power, \( 3^{13} \) in 4 steps

\( 3^{13} \) means 13 threes multiplied: 12 multiplications one by one. For \( b = 10^{18} \) that is far too slow.

The trick: \( 13 = 8 + 4 + 1 \). So \( 3^{13} = 3^8 \cdot 3^4 \cdot 3^1 \). Writing 13 as a sum of 1, 2, 4, 8, … is writing it in binary, as in Bits: 13 is 1101. You get \( 3^2, 3^4, 3^8 \) by squaring again and again.


long long power(long long a, long long b, long long m) {   // a^b % m
    long long result = 1 % m;              // 1 % m, so it is also right for m = 1
    a %= m;                                // make a small first, so a * a fits
    while (b > 0) {
        if (b % 2 == 1)                    // this bit of b is 1: we need this power
            result = result * a % m;
        a = a * a % m;                     // a, a^2, a^4, a^8, ...
        b /= 2;
    }
    return result;
}

Why 1 % m and not 1? For \( m = 1 \) the answer must be 0. With \( b = 0 \) the loop never runs. Both a and result stay below \( m \le 10^9 + 7 \). So a * a is below \( 2 \cdot 10^{18} \) and fits in long long.

Change it to fit

The default: use long long, and take % m after every \( + \) and every \( \times \). Then each problem changes one line.

  • The sum of many numbers, mod m. 
    
sum = (sum + a[i]) % m;                // sum stays below m
  • The product of many numbers, mod m. Take a[i] % m too, because a[i] can be big. 
    
prod = prod * (a[i] % m) % m;          // both are below m, the product fits in long long
  • A difference, mod m. x - y can be negative. Add m, then take % again. 
    
long long d = ((x - y) % m + m) % m;   // always from 0 to m - 1
  • A big power, mod m. Call power(a, b, m). Never a loop of \( b \) multiplications.
  • The last digit. The last digit is the remainder by 10. The last digit of \( 7^{100} \) is power(7, 100, 10), which is 1.

Solve one together

Problem. There are \( n \) lamps. Each lamp is on or off. In how many ways can you set them, so that at least one lamp is on? Print the answer modulo \( 10^9 + 7 \). Limits: \( 1 \le n \le 10^{18} \).

  1. What is asked? The number of on/off settings with at least one lamp on, as a remainder.
  2. A small example by hand. For \( n = 2 \): off-off, off-on, on-off, on-on. Three of the four have a lamp on.
    n123
    all settings248
    at least one on137
  3. The idea. Each lamp has 2 choices, so there are \( 2^n \) settings. Only one of them has all lamps off. The answer is \( 2^n - 1 \). Compute \( 2^n \bmod (10^9 + 7) \) with power. Then subtract 1 with the safe difference form.
  4. Why is it fast enough? \( n \) is up to \( 10^{18} \). power halves it each step: about 60 steps. A loop of \( 10^{18} \) multiplications would never finish.

#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007;          // 10^9 + 7

long long power(long long a, long long b, long long m) {
    long long result = 1 % m;
    a %= m;
    while (b > 0) {
        if (b % 2 == 1) result = result * a % m;
        a = a * a % m;
        b /= 2;
    }
    return result;
}

int main() {
    long long n;
    cin >> n;
    long long all = power(2, n, MOD);              // 2^n % MOD
    cout << ((all - 1) % MOD + MOD) % MOD << "\n"; // the safe form of all - 1
}

Speed: \( + \), \( - \) and \( \times \) with % are \( O(1) \). Fast power is \( O(\log b) \): about 60 steps for \( b = 10^{18} \).

Wrong ideas people get

  • You may think: I can take the remainder once, at the end.

    The truth: The number overflows long before the end. Take it after every \( + \) and every \( \times \).

  • You may think: In C++, a % m is never negative.

    The truth: If a is negative, the result is negative or 0. -7 % 5 is -2. Use ((a % m) + m) % m.

  • You may think: A bigger number has a bigger remainder, so I can compare remainders.

    The truth: No. With \( m = 10 \), 12 gives 2 but 9 gives 9. Never take min or max of remainders.

  • You may think: Division works with remainders like \( + \) and \( \times \).

    The truth: No. The table above shows 30 / 6 going wrong after the mod. Division needs a different tool (see "Not now").

Common mistakes

  • Two int values in a * b % m. The product overflows before the %. Use long long, or write 1LL * a * b % m.
  • Writing 10^9 + 7 in C++. Here ^ is not a power: this prints 26. Write 1000000007.
  • Forgetting a %= m at the start of power. With \( a = 10^{18} \), a * a overflows.

Check yourself

  1. What does C++ print for -8 % 3? What is the true remainder, from 0 to 2?
    Answer

    C++ prints -2. The true remainder is \( (-2 + 3) \bmod 3 = 1 \).

  2. What is the last digit of \( 3^{13} \)?
    Answer

    3. \( 3^{13} = 1594323 \), and the last digit is the remainder by 10. In code: power(3, 13, 10).

  3. About how many steps does power(2, b, m) make for \( b = 10^9 \)?
    Answer

    About 30. Each step halves b, and halving \( 10^9 \) down to 0 takes about 30 steps.
