The template

This template is a full program. Here solve() reads an array and prints YES if its sum is even. For a new problem you change only solve(). The rest stays the same.


#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    long long sum = 0;
    for (int x : a) sum += x;

    if (sum % 2 == 0) cout << "YES\n";
    else              cout << "NO\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) solve();
}

The problem has no t? Replace the two lines int t; and cin >> t; with one line: int t = 1; Then solve() runs once.

Small pieces you use every day

Read an array, the short way:


int n;
cin >> n;
vector<long long> a(n);
for (auto &x : a) cin >> x;      // x is each box of a, in turn

auto lets C++ write the type for you; here it is long long. The & makes x the real box of the array, not a copy. Without &, cin fills a copy and the array does not change. More in the C++ reference, part "References and pointers".

Print YES or NO from a bool:


bool ok = (n % 2 == 0);
cout << (ok ? "YES" : "NO") << "\n";   // ? : means: if ok, "YES", else "NO"

A function that gives back a value. void gives back nothing; long long here gives back a number with return:


long long sumOf(const vector<long long> &a) {   // &: no copy; const: a is not changed
    long long s = 0;
    for (long long x : a) s += x;
    return s;                                      // the caller gets s
}
// in solve(): cout << sumOf(a) << "\n";   for a = {1, 2, 3} it prints 6

Print an array on one line:


for (int i = 0; i < n; i++) cout << a[i] << " ";
cout << "\n";

Solve one together

Problem (4A, Watermelon, from the first lesson). The input is one number \( w \), with \( 1 \le w \le 100 \). Print YES if \( w \) is even and bigger than 2, else NO. Turn the template into a solution.

  1. What is asked? One answer for one number. There is no t in the input, so solve() must run once.
  2. Change main. Replace the lines int t; and cin >> t; with int t = 1;. The while line stays.
  3. Write solve(). It reads w and prints YES or NO. The array and the sum are gone: this problem does not need them.
  4. What stays? The two include lines and the two fast lines. They are the same for every problem.
  5. Is it right? With the sample input 8 it must print YES. How to run it and check this is the next lesson.

#include <bits/stdc++.h>
using namespace std;

void solve() {
    int w;
    cin >> w;
    if (w % 2 == 0 && w > 2) cout << "YES\n";   // even, and not 2
    else cout << "NO\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;                  // 4A has no t: solve() runs once
    while (t--) solve();
}

Wrong ideas people get

  • You may think: A message like "Enter n:" makes the program nicer.

    The truth: The judge reads every character you print. Any extra text makes the answer wrong.

  • You may think: It makes no difference if the variables are inside or outside solve().

    The truth: A global variable keeps its value from the last test case. Keep it inside solve(), or reset it at the start of every test case.

Common mistakes

  • You use endl. It is slow when you print many lines. Use "\n".
  • You mix scanf/printf with cin/cout after sync_with_stdio(false). The order of the output can break. Use only cin and cout.
  • You write for (auto x : a) cin >> x; without &. The numbers go into a copy. The array stays full of zeros.

Check yourself

  1. The problem has no number of test cases t. What do you change in the template?
    Answer

    Replace the two lines int t; and cin >> t; with one line: int t = 1;. Then solve() runs once. If you delete only cin >> t; and add int t = 1;, the code has t twice and does not compile.

  2. Why do the variables live inside solve(), not outside it?
    Answer

    Each call of solve() makes them new. So no value from the last test case is left over. A global variable must be reset by you at the start of every test case.

  3. Your program prints Answer: 3. The expected output is 3. Is it accepted?
    Answer

    No. You get Wrong answer. Print only 3.
