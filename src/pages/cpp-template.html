Start every problem from the same small file. Then you think about the problem, not about the setup.

The template

This template is a full program. Here solve() reads an array and prints YES if its sum is even. For a new problem you change only solve().


#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    long long sum = 0;
    for (int x : a) sum += x;

    if (sum % 2 == 0) cout << "YES\n";
    else              cout << "NO\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) solve();
}

Input 2 / 3 / 1 2 3 / 2 / 1 2 (two test cases) gives YES then NO.

The problem has no t? Delete cin >> t; and write int t = 1;.

Small pieces you use every day

Read an array, the short way:


int n;
cin >> n;
vector<long long> a(n);
for (auto &x : a) cin >> x;      // the & is needed: it writes into the array

Print YES or NO from a bool:


bool ok = (n % 2 == 0);
cout << (ok ? "YES" : "NO") << "\n";

Print an array on one line:


for (int i = 0; i < n; i++) cout << a[i] << " ";
cout << "\n";

Common mistakes

  • You use endl. It is slow when you print many lines. Use "\n".
  • You mix scanf/printf with cin/cout after sync_with_stdio(false). The order of the input and output can break. Use only cin and cout.
  • You make a global array and forget to clear it for the next test case. Keep variables inside solve().
  • You write for (auto x : a) cin >> x; without &. The array stays empty.
