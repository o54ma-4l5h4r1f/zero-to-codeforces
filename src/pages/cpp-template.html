The template

This template is a full program. Here solve() reads an array and prints YES if its sum is even. For a new problem you change only solve(). The rest stays the same.


#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    long long sum = 0;
    for (int x : a) sum += x;

    if (sum % 2 == 0) cout << "YES\n";
    else              cout << "NO\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) solve();
}

Every line in plain words

LineWhat it does
#include <bits/stdc++.h>Brings in all of standard C++ with one line: cin, vector, sort and the rest.
using namespace std;Lets you write cin, not std::cin.
void solve() {A function that solves one test case. void: it returns nothing; it prints.
int n; cin >> n;Reads the size of the array.
vector<int> a(n);An array of n numbers, at places 0 to n - 1.
for (...) cin >> a[i];Reads the n numbers, one by one.
long long sum = 0;A number type that holds bigger values than int. Start at 0.
for (int x : a) sum += x;x takes each value of a in turn. We add it to sum.
if ... cout << "YES\n";Prints the answer. "\n" ends the line.
int main() {The program starts here.
ios::sync_with_stdio(false);
cin.tie(nullptr);		Two lines that make cin and cout fast. You need them for big input, like 200 000 numbers. Always keep them.
int t; cin >> t;Reads the number of test cases.
while (t--) solve();The loop checks t, then makes it 1 smaller. So solve() runs exactly t times.

All variables live inside solve(). So every test case starts with fresh variables. Nothing is left over from the last test.

The problem has no t? Delete cin >> t; and write int t = 1; instead.

Small pieces you use every day

Read an array, the short way:


int n;
cin >> n;
vector<long long> a(n);
for (auto &x : a) cin >> x;      // the & is needed: it writes into the array

Print YES or NO from a bool:


bool ok = (n % 2 == 0);
cout << (ok ? "YES" : "NO") << "\n";

Print an array on one line:


for (int i = 0; i < n; i++) cout << a[i] << " ";
cout << "\n";

Solve one together

Problem. You wrote the template above. Run it on your computer with this sample. Check it before you submit.
Sample input: 2, then 3 and 1 2 3, then 2 and 1 2. Expected output: YES, then NO.

  1. Where does the input come from? cin reads from the standard input. On your computer this is what you type or paste. On the judge it is the test file. cout writes to the standard output. The judge compares what you print with the right answer. So print only the answer, no extra words.
  2. Save the file. Save the code as a.cpp in a folder.
  3. Compile it. Open a terminal in that folder. Type this line and press Enter: 
    g++ -std=c++17 -Wall a.cpp -o a

    g++ is the compiler. It turns your code into a program named a. -std=c++17 picks the C++ version. -Wall prints warnings: hints about likely bugs. Read them.

  4. Run it. Type ./a on Linux or Mac, or .\a on Windows. The program now waits for input. Copy the sample input from the problem page, paste it, and press Enter. 
    2
3
1 2 3
2
1 2
YES
NO

    The first five lines are what you pasted. The last two lines are what your program printed.

  5. Compare. Compare each line with the expected output, letter by letter. YES is not Yes. Same? Test every sample of the problem the same way. Then submit.

No compiler on your computer yet? Codeforces has a Custom Invocation page in the Problemset menu. Paste the code and the input there, then click Run. Use it until your own computer is ready.

Wrong ideas people get

  • You may think: The code compiles, so it is correct.

    The truth: Compiling checks only the spelling, not the idea. Run the samples to test the idea.

  • You may think: I do not need to test the samples myself. The judge will tell me.

    The truth: In a contest every wrong submit costs you points. Testing a sample takes 30 seconds.

  • You may think: A message like "Enter n:" makes the program nicer.

    The truth: The judge reads every character you print. Any extra text makes the answer wrong.

Common mistakes

  • You use endl. It is slow when you print many lines. Use "\n".
  • You mix scanf/printf with cin/cout after sync_with_stdio(false). The order of the output can break. Use only cin and cout.
  • You write for (auto x : a) cin >> x; without &. The numbers go into a copy. The array stays full of zeros.

Check yourself

  1. The problem has no number of test cases t. What do you change in the template?
    Answer

    Delete cin >> t; and write int t = 1;. Then solve() runs once.

  2. Why do the variables live inside solve(), not outside it?
    Answer

    Each call of solve() makes them new. So no value from the last test case is left over.

  3. Your program prints Answer: 3. The expected output is 3. Is it accepted?
    Answer

    No. You get Wrong answer. Print only 3.
