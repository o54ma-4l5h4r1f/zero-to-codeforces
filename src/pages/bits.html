Inside the computer every number is a row of 0s and 1s. You can read and change each of them with very fast operators.

Spot it

  • The statement uses AND, OR, XOR (written &, |, ^ or ⊕).
  • Powers of two: 1, 2, 4, 8, … or "double it", "divide by 2".
  • n ≤ 20 and you must choose some of the items → try every subset with a mask.
  • "Every value appears twice, but one appears once" → XOR of everything.

Three ways to understand it

1 · Story — a row of light switches

Think of a row of switches. Each one is on (1) or off (0). The first switch from the right is worth 1, the next 2, then 4, then 8. The number is the sum of the switches that are on.

The operators AND, OR and XOR look at each switch position alone. Nothing is carried to the next position, so they are simple and fast.

2 · Picture — 13 in binary, and the operators

13 = 8 + 4 + 1, so 13 is 1101. Each digit is one bit. Bits are counted from the right, from 0.

XOR facts: a ^ a = 0, a ^ 0 = a, and the order does not matter. So if you XOR a list, equal values cancel in pairs.

3 · Code — the tricks, then all subsets


int x = 13;                                // 1101
bool on = (x >> 2) & 1;                    // is bit 2 on?        -> true
int a = x | (1 << 1);                      // set bit 1           -> 1111 = 15
int b = x & ~(1 << 0);                     // clear bit 0         -> 1100 = 12
int c = x ^ (1 << 3);                      // flip bit 3          -> 0101 = 5
int ones = __builtin_popcount(x);          // how many 1 bits     -> 3
bool pow2 = x > 0 && (x & (x - 1)) == 0;   // is x a power of two? -> false
long long big = 1LL << 40;                 // for k >= 31 you need 1LL

For a long long use __builtin_popcountll(x).

A subset as a mask. You have n items. A number from 0 to 2n − 1 is one choice: bit i is 1 → item i is taken. Example with n = 3: mask 5 = 101 means "take items 0 and 2".

Task: how many subsets of the array have sum exactly x? (n ≤ 20)


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    long long x;
    cin >> n >> x;                              // n <= 20
    vector<long long> a(n);
    for (auto &v : a) cin >> v;
    int ways = 0;
    for (int mask = 0; mask < (1 << n); mask++) {   // every subset, one by one
        long long sum = 0;
        for (int i = 0; i < n; i++)
            if ((mask >> i) & 1) sum += a[i];       // item i is in this subset
        if (sum == x) ways++;
    }
    cout << ways << "\n";
}

The same job can be done with recursion ("take it or skip it"). The mask loop is shorter to write.

Speed: every operator is O(1). All subsets: O(2^n · n). Fine for n ≤ 20 (about 20 million steps), too slow for n = 30.

Common mistakes

  • Operator precedence: x & 1 == 0 means x & (1 == 0). Always use brackets: (x & 1) == 0.
  • 1 << k with k ≥ 31 overflows, because 1 is an int. Write 1LL << k.
  • ^ is XOR, not power. 2 ^ 3 is 1, not 8. For 2k write 1 << k.
  • && and & are different. && is for conditions (true/false). & works on the bits.
