Inside the computer every number is a row of 0s and 1s. Very fast operators read and change each of them.

Before this lesson

  • You can split a number into digits with % 10 and / 10 → Basic math. This lesson does the same with 2: 13 is \( 8 + 4 + 1 \), or 1101 in binary.
  • You know "try every option" and its cost → Brute force
  • You know that an int overflows above about \( 2 \cdot 10^9 \) → int or long long?

Spot it

  • The statement uses AND, OR, XOR (written &, |, ^ or ⊕).
  • Powers of two: 1, 2, 4, 8, … or "double it", "divide by 2".
  • \( n \le 20 \) and you must choose some of the items. Try every subset with a mask.
  • "Every value appears twice, but one value appears once." XOR everything.

Three ways to understand it

1 · Story — a row of light switches

Think of a row of switches. Each one is on (1) or off (0). The switch on the right is worth 1, the next 2, then 4, then 8. The number is the sum of the switches that are on.

The operators AND, OR and XOR look at each position alone. Nothing is carried to the next position.

2 · Picture — AND, OR, XOR, one bit at a time

First the rules for one bit. This is the truth table:

xyx & y (AND)x | y (OR)x ^ y (XOR)
00000
01011
10011
11110

AND is 1 only if both bits are 1. OR is 1 if at least one is 1. XOR is 1 only when the two bits are different. Now apply the rules to 12 and 10:

XOR on numbers. 5 ^ 5 is 0: every bit meets an equal bit. 5 ^ 0 is 5: nothing changes. 3 ^ 5 ^ 3 is 5: the two 3s cancel. The rule: x ^ x = 0, x ^ 0 = x, and the order does not matter. So equal values cancel in pairs.

3 · Code — the operators, and a subset as a mask


int a = 12, b = 10;              // 1100 and 1010
cout << (a & b) << "\n";          // 8   = 1000
cout << (a | b) << "\n";          // 14  = 1110
cout << (a ^ b) << "\n";          // 6   = 0110
cout << (a << 1) << "\n";         // 24  = 11000: all bits move left = times 2
cout << (a >> 1) << "\n";         // 6   = 110: all bits move right = divide by 2
cout << (1 << 5) << "\n";         // 32  = 2^5: only bit 5 is on

~x flips every bit of x. On this page we use it only inside x & ~(1 << k) (see Change it to fit). On a whole number it gives a negative result: ~x is always -x - 1, so ~12 is -13.

A subset as a mask. You have \( n \) items, numbered from 0. A number mask is one choice: if bit i is 1, item i is taken. With \( n = 3 \), mask 5 is 101: take items 0 and 2. The masks 0 to 7 are all \( 2^3 = 8 \) choices. You see all 8 in "Solve one together".


for (int mask = 0; mask < (1 << n); mask++)    // every subset, one by one
    for (int i = 0; i < n; i++)
        if ((mask >> i) & 1) { /* item i is in this subset */ }

Change it to fit

Each trick below changes one line. In all of them \( x = 13 \), which is 1101, and \( k \) is a bit number.

  • Test bit k. Move bit k to the right end, then keep only that bit. 
    
bool on = (x >> k) & 1;             // 1 if bit k is on, else 0
  • Set bit k (make it 1). OR with a mask that has only bit k. 
    
x = x | (1 << k);
  • Clear bit k (make it 0). AND with a mask where every bit is 1 except bit k. 
    
x = x & ~(1 << k);
  • Flip bit k (0 becomes 1, 1 becomes 0). XOR with the mask. 
    
x = x ^ (1 << k);
  • Count the 1 bits. For 13 the answer is 3. For a long long, write __builtin_popcountll(x). 
    
int ones = __builtin_popcount(x);
  • Find the one number without a pair. All values come twice, one comes once. XOR all of them: the pairs cancel. For 4 7 4 9 9 the answer is 7. 
    
int r = 0;
for (int v : a) r ^= v;

Which one do I use? To loop over subsets, use the mask loop of Code 3. To test a bit, always write (x >> k) & 1.

Solve one together

Problem. You get \( n \) numbers and a number \( x \). How many subsets of the numbers have sum exactly \( x \)? Limits: \( 1 \le n \le 20 \), numbers up to \( 10^9 \).

  1. What is asked? Count the choices of items whose sum is \( x \). The empty choice counts too, if \( x = 0 \).
  2. A small example by hand. The numbers are 3, 5, 2 (items 0, 1, 2) and \( x = 5 \). Bit 0 is the right digit.
    maskbitsitems takensum
    0000none0
    100133
    201055
    30113, 58
    410022
    51013, 25
    61105, 27
    71113, 5, 210

    Two masks have sum 5. The answer is 2.

  3. The idea. Try every mask from 0 to \( 2^n - 1 \). For each mask, add the items whose bit is on. Count the masks with sum \( x \).
  4. Why is it fast enough? \( 2^{20} \) is about \( 10^6 \) masks. Each mask needs a loop of 20. That is \( 2 \cdot 10^7 \) steps, far below \( 10^8 \).

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    long long x;
    cin >> n >> x;                                  // n <= 20
    vector<long long> a(n);
    for (auto &v : a) cin >> v;
    int ways = 0;
    for (int mask = 0; mask < (1 << n); mask++) {   // every subset, one by one
        long long sum = 0;                           // up to 20 * 10^9: long long
        for (int i = 0; i < n; i++)
            if ((mask >> i) & 1) sum += a[i];       // item i is in this subset
        if (sum == x) ways++;
    }
    cout << ways << "\n";
}

Speed: every operator is \( O(1) \). All subsets cost \( O(2^n \cdot n) \): fine for \( n \le 20 \), too slow for \( n = 30 \).

Wrong ideas people get

  • You may think: In C++, ^ means power, so 2 ^ 3 is 8.

    The truth: It is XOR: 2 ^ 3 is 1. For \( 2^k \), write 1 << k.

  • You may think: The test x & 1 == 0 checks that x is even.

    The truth: C++ does == before &. So it computes x & (1 == 0), which is x & 0, always 0. This is operator precedence. For x = 6:

    
if (x & 1 == 0) cout << "even"; else cout << "odd";     // prints odd. Wrong!
if ((x & 1) == 0) cout << "even"; else cout << "odd";   // prints even

    Always put brackets around &, | and ^.

  • You may think: Trying all subsets is fast enough for \( n = 30 \).

    The truth: Each new item doubles the number of masks. For \( n = 30 \) that is about \( 10^9 \) masks, times 30: far too slow. The mask loop is for \( n \le 20 \).

Common mistakes

  • 1 << k with \( k \ge 31 \) overflows, because 1 is an int. Write 1LL << k.
  • && instead of &. && joins two conditions (true/false). & works on the bits.
  • __builtin_popcount on a long long. It counts only the low 32 bits. Use __builtin_popcountll.

Not now

  • "Take it or skip it" with a function that calls itself. It does the same job as the mask loop. You learn it in Recursion. Until then, use masks.
  • Why ~12 is -13 (how negative numbers are stored). You do not need it below 1600. Come back after the guide: After 1600.
  • DP over masks. It is a strong tool, but mostly above 1600. Come back after the guide: After 1600.

Check yourself

  1. What is 13 & 6? Write the bits first.
    Answer

    1101 AND 0110 is 0100, which is 4. Only bit 2 is 1 in both.

  2. You have 4 items. Which mask means "take items 0 and 3 only"?
    Answer

    1001 in binary, which is \( 8 + 1 = 9 \).

  3. The array is 4 7 4 9 9. What is the XOR of all of them?
    Answer

    7. The two 4s cancel, the two 9s cancel, and 7 is left.
