The routine

  1. Read the limits first. Look at the constraints, the time limit and the memory limit. They tell you how fast your code must be.
  2. Read the story. Then say the task in one sentence, in your own words.
  3. Read the Input and Output parts. What do you read? What exactly do you print?
  4. Run the samples by hand. Use paper. Get the same answers as the statement.
  5. Read the Note. It is at the end. It often explains the samples.
  6. Look for trap words. See the table below.

Do not write code before step 4 works. If your hand answer is different, you did not understand the task yet.

How to read the limits

Limits are written with powers of 10. \( 10^5 \) means 1 followed by 5 zeros.

You seeSay it asThe number
\( 10^3 \)ten to the 31 000
\( 10^5 \)ten to the 5100 000
\( 2 \cdot 10^5 \)2 times \( 10^5 \)200 000
\( 10^9 \)ten to the 91 000 000 000 (one billion)
\( 10^{18} \)ten to the 181 with 18 zeros

The sign \( \le \) means "less than or equal". So \( 1 \le n \le 2 \cdot 10^5 \) reads: \( n \) is a whole number from 1 to 200 000, and both ends are allowed.

The statement uses a few more signs. Each one with a small example:

You seeIt meansExample
\( a_i \)"a with index \( i \)": the number at place \( i \) of the array a\( a = 5, 7, 9 \): \( a_2 = 7 \)
\( a_1, a_2, \dots, a_n \)\( n \) numbers, counted from 1\( n = 3 \): \( a_1, a_2, a_3 \)
\( [l, r] \)from \( l \) to \( r \), both ends included. It holds \( r - l + 1 \) numbers.\( [2, 5] \): 2, 3, 4, 5. That is 4 numbers.
\( |x| \)\( x \) without its minus sign\( |-4| = 4 \), \( |4| = 4 \)
\( 10^9 + 7 \)the number 1 000 000 007"print the answer modulo \( 10^9 + 7 \)": a later lesson

The biggest values are the ones that break code. The judge always has a test with them.

Four words look alike but mean different things. Here they are on the array 2, 3, 4, 5, 6.

Solve one together

Problem. We read a whole statement, piece by piece. Here it is, in short.
You get \( t \) test cases. Each one is an array \( a_1, \dots, a_n \). Count the places \( i \) (\( 2 \le i \le n \)) where \( a_i > a_{i-1} \). Input: the first line has \( t \) (\( 1 \le t \le 10^4 \)). Each test case has \( n \) (\( 1 \le n \le 2 \cdot 10^5 \)), then \( n \) numbers \( a_i \) (\( 1 \le a_i \le 10^9 \)). The sum of \( n \) over all test cases does not exceed \( 2 \cdot 10^5 \). Output: one number for each test case.

  1. The limits, piece by piece.
    PieceWhat it tells you
    \( 1 \le t \le 10^4 \)Up to 10 000 test cases in one input. Solve each and print each answer.
    \( 1 \le n \le 2 \cdot 10^5 \)One array can have 200 000 numbers. Also \( n = 1 \) is allowed.
    \( 1 \le a_i \le 10^9 \)Each number is up to one billion. It fits in an int.
    sum of \( n \le 2 \cdot 10^5 \)All arrays together have at most 200 000 numbers.

    The "sum of \( n \)" line means: all test cases together are like one test with 200 000 numbers. Do not multiply by \( t \).

  2. The task in one sentence. "How many times does the array go up from one number to the next?"
  3. The sample by hand. Input: 2, then 5 and 1 3 2 4 5, then 1 and 7. In 1, 3, 2, 4, 5 the steps up are 1→3, 2→4 and 4→5. So 3. The array 7 has no pair, so 0. Output: 3 then 0.
  4. Traps. With \( n = 1 \) there is no pair, so the answer is 0. C++ counts from 0, so i goes from 1 to n - 1.
  5. Is it fast enough? We look at each number once. That is 200 000 looks in total, for all tests together. This is tiny work for a computer.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {                        // one round of the loop per test case
        int n;
        cin >> n;
        vector<int> a(n);               // an array of n numbers: a[0] ... a[n-1]
        for (int i = 0; i < n; i++) cin >> a[i];
        int ups = 0;
        for (int i = 1; i < n; i++)      // a[i-1] exists only for i >= 1
            if (a[i] > a[i - 1]) ups++;
        cout << ups << "\n";
    }
}

Wrong ideas people get

  • You may think: With \( 10^4 \) tests and \( n \) up to \( 2 \cdot 10^5 \), the total work is their product.

    The truth: If the statement says "the sum of \( n \) is at most \( 2 \cdot 10^5 \)", all tests together have only \( 2 \cdot 10^5 \) numbers.

  • You may think: My answer differs from the sample answer, so it is wrong.

    The truth: If the statement says "print any valid answer", your answer can be right too. Check it against the rules, not against the sample.

  • You may think: A subsequence and a subarray are the same thing.

    The truth: A subarray has no gaps. A subsequence may have gaps. The task and the answer change completely.

Common mistakes

  • You print "Yes" when the statement asks for "YES". Copy the word from the statement.
  • You forget to read t, so your program reads the wrong numbers.
  • You use a[i - 1] with i = 0. Start the loop at 1.

Check yourself

  1. What is \( 3 \cdot 10^5 \) written as a normal number?
    Answer

    300 000. \( 10^5 \) is 100 000, and 3 times that is 300 000.

  2. Is [1, 3] a subarray of [1, 2, 3]? Is it a subsequence?
    Answer

    Not a subarray: there is a gap where 2 was. It is a subsequence: 1 and 3 keep their order.

  3. Is [2, 1, 2] a permutation of length 3?
    Answer

    No. 2 appears twice and 3 is missing. A permutation of length 3 has 1, 2 and 3, each once.
