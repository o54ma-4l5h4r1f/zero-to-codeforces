A tree is a connected graph with no cycle. One DFS from the root answers most tree questions.

Spot it

  • "n vertices and n − 1 edges", and the graph is connected.
  • "There is exactly one path between every two vertices."
  • "The parent of vertex i is pi", or a boss and workers, or folders inside folders.
  • Words like root, leaf, subtree.

Three ways to understand it

1 · Story — a company

A company has one director. This is the root. Every other person has exactly one boss: the parent. The people directly under you are your children. A person with no workers is a leaf.

Your depth is the number of bosses above you. Your subtree is you and everybody under you. A tree has no cycle: nobody is the boss of their own boss.

2 · Picture — depth and subtree size

d = depth, s = size of the subtree. Two directions of information:

ValueDirectionRuleExample
depthgoes down: parent → childdepth[child] = depth[parent] + 1depth[7] = depth[6] + 1 = 3
sizecomes up: children → parentsize[v] = 1 + sizes of all childrensize[2] = 1 + 1 + 1 = 3

Set "down" values before the call to the child. Collect "up" values after the call returns.

3 · Code — one DFS

The input is n, then n − 1 edges. The root is vertex 1. A tree has no cycle, so you need no visited array: just do not walk back to the parent.


#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> g;
vector<int> depth, sz;

void dfs(int v, int parent) {
    sz[v] = 1;                           // v itself
    for (int to : g[v]) {
        if (to == parent) continue;      // do not go back up
        depth[to] = depth[v] + 1;        // going down: before the call
        dfs(to, v);
        sz[v] += sz[to];                 // coming up: after the call
    }
}

int main() {
    int n;
    cin >> n;
    g.assign(n + 1, vector<int>());
    depth.assign(n + 1, 0);
    sz.assign(n + 1, 0);
    for (int i = 0; i < n - 1; i++) {    // a tree has n - 1 edges
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    dfs(1, 0);                           // the root has no parent: use 0
    for (int v = 1; v <= n; v++)
        cout << v << ": depth " << depth[v] << ", size " << sz[v] << "\n";
}

The other input form gives the parent of each vertex 2..n. Then you add edges from parent to child only, and the if (to == parent) line is not needed:


for (int v = 2; v <= n; v++) {
    int p;
    cin >> p;                 // p is the parent of v
    g[p].push_back(v);        // g[p] = children of p
}

A vertex v is a leaf when it has no children: sz[v] == 1.

Diameter = the longest path in the tree. Run BFS from any vertex and take the farthest vertex a. Run BFS again from a and take the farthest vertex b. The diameter is the path from a to b, and its length is dist[b].

Speed: O(n). The DFS enters every vertex once.

Common mistakes

  • You read n edges. A tree has n − 1 edges.
  • You forget if (to == parent) continue; → the DFS jumps between two vertices forever.
  • You think the root is always 1, or that the edge "a b" means a is the parent. Read the statement.
  • You use sz[v] before the calls to the children are finished. "Up" values are ready only after the loop.
