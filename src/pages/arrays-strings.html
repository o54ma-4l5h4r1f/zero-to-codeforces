An array is a row of numbered boxes, starting at 0. A string is a row of boxes with one letter in each.

Before this lesson

  • You can trace a loop by hand → Do what the statement says
  • You can count the steps of one loop: \( O(n) \) → How much does my code cost?

Spot it

  • The input is "\( n \), then \( n \) numbers". Store them in a vector<int>.
  • The input is a word or a line of letters. Store it in a string.
  • You must find the biggest, the smallest, the sum, or the position of something.
  • You must look at letters one by one: count them, change them, compare neighbours.

Three ways to understand it

1 · Story — a street of houses

A street has 5 houses. Each house has a number on the door and one thing inside. The door number is the index. The thing inside is the value.

In C++ the first house has number 0, not 1. So the last house has number 4, and house 5 does not exist.

2 · Picture — boxes with numbers

Here \( n = 5 \). The boxes are a[0] to a[4].

With \( n \) boxes the indexes go from 0 to \( n - 1 \). The last index is \( n - 1 \), not \( n \). A loop for (int i = 0; i < n; i++) stops at the right place. With i <= n it reads the dotted box. This kind of bug is called off-by-one.

Now one loop finds the biggest value and its index. Press Next.

Characters are numbers. Each box of a string holds one character. Inside the computer a character is a small number. The letters 'a' to 'z' are 26 numbers in a row:

c'a''b''c''d'…'z'
the number inside979899100…122
c - 'a'0123…25

You never need to remember 97. Subtract 'a' and you get the place of the letter, from 0 to 25. Digits work the same: '0' is 48, so '7' - '0' is the number 7.

3 · Code — one loop does almost everything

Array: read \( n \) numbers. Print the sum, the maximum, and its position counted from 1.


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);                 // n boxes: a[0] ... a[n-1]
    for (int i = 0; i < n; i++) cin >> a[i];

    long long sum = 0;
    int best = a[0];                  // start with the first value, not with 0
    int pos = 0;                      // where the maximum is
    for (int i = 0; i < n; i++) {
        sum += a[i];
        if (a[i] > best) {
            best = a[i];
            pos = i;
        }
    }
    cout << sum << " " << best << " " << pos + 1 << "\n";   // +1: people count from 1
}

String: read a word. Make every letter small. Count how many different letters it has.


#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;                              // reads one word (stops at a space)
    vector<bool> seen(26, false);          // seen[0] is for 'a', seen[25] is for 'z'
    int different = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        s[i] = tolower(s[i]);              // 'H' becomes 'h'
        int k = s[i] - 'a';                // 0..25
        if (!seen[k]) {
            seen[k] = true;
            different++;
        }
    }
    cout << s << " " << different << "\n"; // Hello -> hello 4
}

Why (int)s.size()? The next lesson shows the reason with real output. For now, always write it.

Change it to fit

Almost every array problem is the same loop with a small change. The default is the forward loop. Change only the loop line when the problem asks for it.

The problem says…Write this loop\( i \) takes (for \( n = 5 \))
look at every box (DEFAULT)for (int i = 0; i < n; i++)0, 1, 2, 3, 4
start from the end (print reversed, find the last …)for (int i = n - 1; i >= 0; i--)4, 3, 2, 1, 0
compare each box with its right neighbourfor (int i = 0; i + 1 < n; i++)0, 1, 2, 3: pairs (0,1) … (3,4)

In the neighbour loop we read a[i + 1], so i must stop at \( n - 2 \). The condition i + 1 < n does exactly that.

Solve one together

Problem (266A, Stones on the Table). \( n \) stones stand in a row. Each is red, green or blue: the string s uses the letters R, G, B. Remove the fewest stones so that no two neighbours have the same colour. Limits: \( 1 \le n \le 50 \).

  1. What is asked? One number: how many stones to remove.
  2. A small example by hand. s = RRGGGB. Compare each stone with its right neighbour.
    pair (i, i+1)(0,1)(1,2)(2,3)(3,4)(4,5)
    coloursR RR GG GG GG B
    same?yesnoyesyesno

    Three pairs are the same. Remove 3 stones: one R and two G. The answer is 3.

  3. The idea. Each pair of equal neighbours costs exactly one stone. Count those pairs with the neighbour loop.
  4. Why is it fast enough? One loop: \( O(n) \), at most 49 pairs.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    string s;
    cin >> n >> s;
    int removed = 0;
    for (int i = 0; i + 1 < n; i++) {    // pairs (i, i+1); the last i is n-2
        if (s[i] == s[i + 1]) removed++;
    }
    cout << removed << "\n";
}

Speed: one loop over \( n \) boxes is \( O(n) \). Fine for \( n \) up to \( 10^6 \) and more.

Wrong ideas people get

  • You may think: The last element is a[n]. If I am wrong, C++ will tell me.

    The truth: The last element is a[n - 1]. Reading a[n] gives no error message: you may get garbage or a crash.

  • You may think: Starting with best = 0 is always safe for the maximum.

    The truth: If all numbers are negative, the answer 0 is wrong. Start with a[0].

  • You may think: The character '5' is the number 5.

    The truth: The character '5' holds the number 53. Write c - '0' to get 5.

Common mistakes

  • The statement counts from 1, your code counts from 0. Add 1 when you print a position.
  • cout << tolower(c) prints a number like 104. Save it first: char d = tolower(c); then print d.
  • The neighbour loop written as i < n. At the last step it reads a[n]. Write i + 1 < n.

Not now

  • How many times each value appears. The seen array above is the start of a bigger idea. You learn it in Counting.
  • The sum of many pieces of an array. One loop per question is too slow when there are many questions. You learn the fix in Prefix sums.

Check yourself

  1. An array has 8 elements. What is the index of the last one?
    Answer

    7. The indexes go from 0 to \( n - 1 = 7 \).

  2. What is 'e' - 'a'? And '9' - '0'?
    Answer

    4 and 9. The letter e is the fifth letter, so it is number 4 when we count from 0.

  3. What is wrong here: for (int i = 0; i < n; i++) if (a[i] == a[i + 1])?
    Answer

    When i = n - 1, it reads a[n], which does not exist. Write i + 1 < n.
