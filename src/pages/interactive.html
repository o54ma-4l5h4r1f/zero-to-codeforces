Your program talks with the judge. You print a question, the judge answers, and you use the answer to choose the next question.

Spot it

  • The statement says "This is an interactive problem".
  • Something is hidden: a number, an array, a position. You do not get it in the input.
  • You may ask questions in a fixed format, like ? x, and print the answer like ! x.
  • There is a limit: "at most 7 questions", "at most 20 queries".

Three ways to understand it

1 · Story — the guessing game with a real person

Remember the guessing game from Binary search. Now your friend really sits in front of you. You say a number. You wait. Your friend answers. Only then you say the next number.

One danger: you write your question on paper but keep the paper in your pocket. Your friend waits for you, you wait for your friend, for ever. In C++ the "pocket" is the output buffer. To flush = to give the paper to your friend now.

2 · Picture — one dialogue

The judge hides a number from 1 to 100 (here: 37). You print ? q. The judge answers 1 if the hidden number is ≥ q, and 0 if it is smaller. You have 7 questions.

#you printjudge answerswhat you know now
1? 5101 … 50
2? 26126 … 50
3? 38026 … 37
4? 32132 … 37
5? 35135 … 37
6? 36136 … 37
7? 37137 … 37
end! 37–finished; the last line is not a question

Each question cuts the range in half. 100 → 50 → 25 → 13 → 7 → 4 → 2 → 1: 7 questions are enough. In general you need about log2(range) questions. Count this before you code and compare with the limit.

3 · Code — binary search that asks the judge


#include <bits/stdc++.h>
using namespace std;

int main() {
    int lo = 1;                             // hidden >= 1 is true for sure
    int hi = 101;                           // hidden >= 101 is false for sure
    while (hi - lo > 1) {
        int mid = lo + (hi - lo) / 2;
        cout << "? " << mid << endl;        // endl = new line + flush
        int reply;
        cin >> reply;                       // wait for the judge
        if (reply == -1) return 0;          // we broke a rule: stop at once
        if (reply == 1) lo = mid;           // hidden >= mid
        else            hi = mid;           // hidden < mid
    }
    cout << "! " << lo << endl;             // the final answer, also with flush
    return 0;
}

Test it yourself: run the program, think of a number, and type the replies by hand. You are the judge.

Four rules. 1) Flush after every line you print: use endl. This is the one place where endl is better than "\n". 2) Read the reply before you print the next question. 3) Count your questions. One too many = Wrong answer. 4) If the judge replies -1 (or what the statement says), exit at once.

Speed: time is almost never the problem. The real limit is the number of questions.

Common mistakes

  • No flush. The verdict is "Idleness limit exceeded": the judge waited for a question that never came.
  • Wrong format: ?51 without the space, or a missing ! before the answer. Copy the format from the statement.
  • Many test cases: after ! x some problems send one more reply to read. Check the statement.
  • Thinking the samples are a normal input file. They show a dialogue. Your program must work for any hidden value.
