No trick, no formula. Read the rules, then make your program follow them step by step.

Spot it

  • The statement describes a process: "first…, then…, after each step…".
  • The limits are small (n ≤ 100 or n ≤ 1000), so doing every step is fast enough.
  • You understand what to do after one reading. The only work is to write it carefully.
  • Codeforces puts the tag implementation on these problems. Another name is simulation.

Three ways to understand it

1 · Story — cooking from a recipe

A recipe says: "Put 2 eggs. Add sugar. Mix. Repeat 3 times." You do not invent anything. You do each line in the same order.

The statement is your recipe. Each number in it becomes a variable. Each "repeat" becomes a loop. Each "if" stays an if.

2 · Picture — the tram

A tram is empty at the start. At each stop a people exit, then b people enter. How many seats does the tram need? You need the biggest number of people inside at any moment.

Write the variables in a table and change them by hand. This is called a trace.

stopa (exit)b (enter)insidebest
start––00
1030 − 0 + 3 = 33
2253 − 2 + 5 = 66
3426 − 4 + 2 = 46
4404 − 4 + 0 = 06

The answer is 6. If you can fill this table by hand, you can write the code: one row = one turn of the loop.

3 · Code — the table becomes a loop

Use the same names as the statement (n, a, b). Then you can compare your code with the text line by line.


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;                    // number of stops
    cin >> n;
    int inside = 0;           // people in the tram now
    int best = 0;             // the biggest "inside" we saw
    for (int i = 0; i < n; i++) {
        int a, b;             // a people exit, b people enter
        cin >> a >> b;
        inside -= a;          // first they exit
        inside += b;          // then they enter
        best = max(best, inside);
    }
    cout << best << "\n";
}

Many problems have t test cases in one input. Put the solution of one case in a function. Then every case starts with fresh variables.


#include <bits/stdc++.h>
using namespace std;

void solve() {                // solves ONE test case
    int n;
    cin >> n;
    long long sum = 0;        // made new for every test case
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        sum += x;
    }
    cout << sum << "\n";      // one answer per line
}

int main() {
    int t;
    cin >> t;
    while (t--) solve();
}

Speed: you do every step once, so O(number of steps). Check that this number is below about 10^8.

Before you submit: run every sample from the statement. Compare your output with the expected output letter by letter.

Common mistakes

  • Wrong output format. YES is not Yes when the statement asks for exact letters. Do not print extra text like "Answer:".
  • Wrong order of steps. In the tram, people exit before others enter. Follow the order in the statement.
  • A variable keeps its old value in the next test case. Create it inside solve().
  • You forget the smallest input, the edge case. Try n = 1 or n = 2 by hand.
