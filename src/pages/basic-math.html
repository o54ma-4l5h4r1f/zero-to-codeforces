A few small formulas replace a long loop. Learn them once, and many 800 problems become one line.

Before this lesson

  • You know when a number needs long long → int or long long?
  • You know that a loop to \( 10^9 \) or \( 10^{18} \) is too slow → How much does my code cost?

Spot it

  • The numbers go up to \( 10^9 \) or \( 10^{18} \). A loop is too slow, so there must be a formula.
  • The statement talks about even and odd, or divisible numbers, or digits.
  • "How many boxes / buses / steps do you need at least?" This is division that rounds up.
  • "How many numbers from \( l \) to \( r \) are…" or "find the sum \( 1 + 2 + \dots + n \)".

Three ways to understand it

1 · Story — the buses

One bus takes 4 people. In C++, 10 / 4 is 2. Division of two ints throws away the rest: it rounds down. But 2 buses leave 2 people on the street. We need to round up.

Look at more numbers of people \( a \). a % 4 is the rest: the people who do not fill a bus.

If at least one person is left over, we need one more bus. Adding 3 before dividing does exactly that. Why 3? It is one less than the bus size 4. A full bus (rest 0) gets no extra bus.

With letters: \( a \) people and buses of size \( b \). Rounding up is written \( \lceil a / b \rceil \). In C++ write (a + b - 1) / b. This works when \( a \ge 0 \) and \( b > 0 \).

2 · Picture — counting on a number line

How many whole numbers are in \( [l, r] \)? Here \( [l, r] \) means "from \( l \) to \( r \), both included". Take \( l = 5 \) and \( r = 17 \). The answer is 13, not 12. The count is \( r - l + 1 \), because both ends count.

How many multiples of 3 are in \( [5, 17] \)? A multiple of 3 is 3, 6, 9, 12 and so on.

Count them with two easy questions:

  • Multiples of 3 from 1 to 17: \( \lfloor 17 / 3 \rfloor = 5 \). They are 3, 6, 9, 12, 15. The sign \( \lfloor x \rfloor \) means "round \( x \) down", like 17 / 3 in C++.
  • Multiples of 3 from 1 to 4, the part before \( l \): \( \lfloor 4 / 3 \rfloor = 1 \). It is the 3.
  • Take away the part before \( l \): \( 5 - 1 = 4 \).
\[ \text{multiples of } k \text{ in } [l, r] = \lfloor r / k \rfloor - \lfloor (l - 1) / k \rfloor \]

Even and odd. A number is even when x % 2 == 0. The rules for two numbers \( a \) and \( b \):

Sum of \( 1 + 2 + \dots + n \). Take \( n = 10 \). Pair the ends: \( 1 + 10 = 11 \), \( 2 + 9 = 11 \), and so on. There are 5 pairs of 11, so the sum is 55. In general:

\[ 1 + 2 + \dots + n = \frac{n \cdot (n + 1)}{2} \]

3 · Code — small helpers


long long ceilDiv(long long a, long long b) {      // a / b rounded up (a >= 0, b > 0)
    return (a + b - 1) / b;
}

long long sumTo(long long n) {                     // 1 + 2 + ... + n
    return n * (n + 1) / 2;
}

long long multiples(long long l, long long r, long long k) {   // in [l..r], l >= 1
    return r / k - (l - 1) / k;
}

Digits. x % 10 is the last digit. x / 10 removes it. Repeat until \( x = 0 \). For 4072: the digits come out as 2, 7, 0, 4, and their sum is 13.


#include <bits/stdc++.h>
using namespace std;

int main() {
    long long x;
    cin >> x;                  // x >= 1
    int sum = 0, digits = 0;
    while (x > 0) {
        sum += x % 10;         // take the last digit
        digits++;
        x /= 10;               // remove the last digit
    }
    cout << sum << " " << digits << "\n";    // 4072 -> 13 4
}

Solve one together

Problem (1A, Theatre Square). A square is \( n \) metres by \( m \) metres. You cover it with square stones of size \( a \) by \( a \). Stones may go over the edge, but you cannot break them. How many stones do you need at least? Limits: \( 1 \le n, m, a \le 10^9 \).

  1. What is asked? One number: the fewest stones.
  2. A small example by hand. \( n = 6 \), \( m = 6 \), \( a = 4 \). Along one side, one stone covers 4 metres. 2 metres are left, so we need a second stone: \( \lceil 6 / 4 \rceil = 2 \). The same on the other side. In total \( 2 \cdot 2 = 4 \) stones.
  3. The idea. The stones on each side are a division that rounds up. The answer is the product of the two. \[ \lceil n / a \rceil \cdot \lceil m / a \rceil \]
  4. Why is it fast enough? Two divisions and one product: \( O(1) \). But the answer can reach \( 10^9 \cdot 10^9 = 10^{18} \), so we use long long.

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, m, a;                  // long long: the answer can be 10^18
    cin >> n >> m >> a;
    long long along = (n + a - 1) / a;  // stones along n, rounded up
    long long across = (m + a - 1) / a; // stones along m, rounded up
    cout << along * across << "\n";
}

Speed: a formula is \( O(1) \). The digits loop is \( O(\text{number of digits}) \): at most 19 turns for a long long.

Wrong ideas people get

  • You may think: In C++, ceil(10 / 4) gives 3.

    The truth: It gives 2. 10 / 4 is already 2 before ceil runs. Stay with integers and write (a + b - 1) / b.

  • You may think: The count of numbers from \( l \) to \( r \) is \( r - l \).

    The truth: It is \( r - l + 1 \), because both ends are in. From 5 to 7 there are 3 numbers.

  • You may think: The test x % 2 == 1 always finds odd numbers.

    The truth: With a negative number the remainder is negative: -7 % 2 is -1. Write x % 2 != 0.

Common mistakes

  • n * (n + 1) / 2 with int n can overflow. It overflows from \( n = 46341 \), about \( 4.6 \cdot 10^4 \). Use long long when \( n \) can pass \( 10^4 \).
  • Two numbers up to \( 10^9 \) multiplied in int. The product needs long long before you multiply.
  • The digits loop does nothing for \( x = 0 \). If 0 is a possible input, handle it alone.

Not now

  • Primes, divisors, GCD. They are the next level of the same math. You learn them in GCD, primes, divisors.
  • "Print the answer modulo \( 10^9 + 7 \)". That needs its own rules for %. You learn them in Mod and fast power.

Check yourself

  1. 23 people, a bus takes 5. How many buses? Write the C++ expression.
    Answer

    (23 + 5 - 1) / 5 = 27 / 5 = 5 buses. Four full buses carry 20, and the fifth carries 3.

  2. How many multiples of 4 are in \( [10, 30] \)?
    Answer

    \( \lfloor 30 / 4 \rfloor - \lfloor 9 / 4 \rfloor = 7 - 2 = 5 \). They are 12, 16, 20, 24, 28.

  3. \( a \) is odd and \( b \) is odd. Is \( a + b \) even or odd? And \( a \cdot b \)?
    Answer

    \( a + b \) is even, like \( 5 + 3 = 8 \). \( a \cdot b \) is odd, like \( 5 \cdot 3 = 15 \).
