Four small tools for whole numbers: GCD, a prime test, the list of divisors, and the sieve. All are short and you can learn them by heart.

Spot it

  • The words divisible, divisor, multiple, prime, "common divisor" are in the statement.
  • "The biggest number that divides all of them" → GCD. "The smallest number divisible by all of them" → LCM.
  • One number up to 1012 or 109 → a loop up to its square root.
  • Many numbers up to 106 or 107, and you ask "is it prime?" for each → the sieve.

Three ways to understand it

1 · Story — cutting a rectangle into squares (GCD)

You have a paper of 30 × 18. You want to cut it into equal squares, as big as possible, with no paper left.

Cut one 18 × 18 square. A 18 × 12 piece is left. Cut one 12 × 12 square. A 12 × 6 piece is left. It is exactly two 6 × 6 squares. So the answer is 6 = gcd(30, 18).

This is Euclid's algorithm: replace (a, b) by (b, a % b) until b is 0. It needs very few steps, even for 1018.

2 · Picture — the sieve: cross out multiples, 2 to 30

Write all numbers. Take the first number that is not crossed out: it is prime. Cross out its multiples. Repeat.

Why start at p · p? The smaller multiples (2p, 3p, …) are already crossed out by smaller primes.

3 · Code — the four tools

GCD and LCM. C++ has gcd(a, b) (C++17) and the older __gcd(a, b). For LCM divide first, then multiply, so the number stays small.


long long a = 30, b = 18;
long long g = gcd(a, b);               // 6
long long l = a / g * b;               // lcm = 90. Divide first, then multiply

Prime test and divisors. Divisors come in pairs: if i divides n, then n / i also divides n. One of the two is ≤ sqrt(n). So the loop stops at i * i <= n.


bool isPrime(long long n) {
    if (n < 2) return false;               // 0 and 1 are not prime
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;      // found a divisor
    return true;
}

vector<long long> divisors(long long n) {
    vector<long long> small, big;
    for (long long i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            small.push_back(i);                    // the small one of the pair
            if (i != n / i) big.push_back(n / i);  // the big one (not twice for 6 * 6)
        }
    }
    small.insert(small.end(), big.rbegin(), big.rend());   // all, small -> big
    return small;
}

// prime factorisation: 60 -> 2 2 3 5
vector<long long> factorise(long long n) {
    vector<long long> primes;
    for (long long i = 2; i * i <= n; i++) {
        while (n % i == 0) {               // take i out as many times as we can
            primes.push_back(i);
            n /= i;
        }
    }
    if (n > 1) primes.push_back(n);        // what is left is one big prime
    return primes;
}

Sieve. Use it when you need "is x prime?" for many x. This program prints all primes up to n.


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;                                       // n up to about 10^7
    vector<bool> isPrime(n + 1, true);
    isPrime[0] = false;
    if (n >= 1) isPrime[1] = false;
    for (long long p = 2; p * p <= n; p++) {
        if (!isPrime[p]) continue;                  // p is crossed out, skip it
        for (long long x = p * p; x <= n; x += p)
            isPrime[x] = false;                     // cross out the multiples of p
    }
    for (int x = 2; x <= n; x++)
        if (isPrime[x]) cout << x << " ";
    cout << "\n";
}

Speed: gcd O(log n). Prime test, divisors and factorisation O(sqrt n): fine for one n up to 10^12. Sieve: about O(n log log n), fine for n = 10^7.

Common mistakes

  • i * i with int i can overflow when n is near 2·109 or bigger. Make i a long long.
  • Saying that 1 is prime. It is not. The smallest prime is 2.
  • LCM as a * b / g. The product can overflow. Write a / g * b.
  • A loop to sqrt(n) for each of 105 big numbers. That is too slow. Build one sieve first.
