Five small tools for whole numbers: GCD, divisors, the prime test, factorisation and the sieve. Each one is a short loop you can learn by heart.

Before this lesson

  • You know % and what "divisible" means → Basic math
  • You can count the steps of a loop → Limits → speed
  • You know when i * i needs long long → int or long long?

Spot it

  • The words divisor, multiple, prime or "common divisor" are in the statement.
  • "The biggest number that divides all of them" is the GCD. "The smallest number that all of them divide" is the LCM.
  • One number up to \( 10^{12} \): a loop up to its square root is fast enough.
  • Many numbers up to \( 10^6 \) or \( 10^7 \), and "is it prime?" for each: the sieve.

Three ways to understand it

1 · Story — a number as a rectangle of tiles

You have 36 square tiles. You build a full rectangle with them. You can build \( 1 \times 36 \), \( 2 \times 18 \), \( 3 \times 12 \), \( 4 \times 9 \) or \( 6 \times 6 \).

Each side is a divisor of 36: it divides 36 with no remainder, so 36 % 4 == 0. And 36 is a multiple of 4. The sides come in pairs. With 7 tiles you can build only \( 1 \times 7 \). So 7 is a prime: its only divisors are 1 and 7.

A prime has exactly two divisors: 1 and itself. 9 is not a prime, because \( 9 = 3 \cdot 3 \).

2 · Picture — the divisors of 36 come in pairs

Try every small side i. If 36 is divisible by i, the other side is 36 / i.

So the divisors are 1, 2, 3, 4, 6, 9, 12, 18, 36. At \( i = 6 \) both sides are 6. Count it once.

The small side is never bigger than 6, because \( 6 \cdot 6 = 36 \). So we stop when i * i is bigger than n. This stop point is the square root: \( \sqrt{36} = 6 \). For \( n = 10^{12} \) the loop makes only \( 10^6 \) steps.

3 · Code — five tools, one part each

Part A · GCD and LCM

Example: \( \gcd(10, 6) = 2 \), the biggest number that divides both. The LCM of 10 and 6 is 30, the smallest number that both divide.

Euclid's algorithm finds the GCD. Picture a paper of \( 10 \times 6 \). Cut the biggest squares you can, again and again. The last square size is the GCD.

C++17 already has this loop: gcd(a, b). Use it. For the LCM, divide first, then multiply:


long long a = 10, b = 6;
long long g = gcd(a, b);               // 2
long long l = a / g * b;               // lcm = 30. Divide first, so it stays small

gcd(0, x) is x. This helps in Change it to fit, below.

Part B · All divisors of n

This is the table of Picture 2 as code. For 36 it returns 1 2 3 4 6 9 12 18 36.


vector<long long> divisors(long long n) {
    vector<long long> small, big;
    for (long long i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            small.push_back(i);                    // the small side of the pair
            if (i != n / i) big.push_back(n / i);  // the big side (not twice for 6 * 6)
        }
    }
    reverse(big.begin(), big.end());                // big sides, now small to big
    for (long long x : big) small.push_back(x);    // all of them, small to big
    return small;
}

Part C · Is n prime?

Example: 91. Try 2, 3, 4, 5, 6, 7. Then 91 is divisible by 7, because \( 91 = 7 \cdot 13 \). So 91 is not prime. For 97 we try 2 to 9 and find nothing, so 97 is prime.


bool isPrime(long long n) {
    if (n < 2) return false;               // 0 and 1 are not prime
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;      // found a divisor
    return true;
}

Part D · n as a product of primes

Example: 60. Divide by 2 while you can: 60, 30, 15. Divide by 3: 5. Now \( 4 \cdot 4 = 16 \) is bigger than 5, so stop. The 5 that is left is a prime. So \( 60 = 2 \cdot 2 \cdot 3 \cdot 5 \).


vector<long long> factorise(long long n) {   // 60 -> 2 2 3 5
    vector<long long> primes;
    for (long long i = 2; i * i <= n; i++) {
        while (n % i == 0) {               // take i out as many times as we can
            primes.push_back(i);
            n /= i;
        }
    }
    if (n > 1) primes.push_back(n);        // what is left is one big prime
    return primes;
}

Part E · The sieve: all primes up to n

Write the numbers 1 to 30. Take the next number that is not crossed out: it is prime. Cross out its multiples. Repeat.

This program prints all primes up to n.


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;                                       // n up to about 10^7
    vector<bool> isPrime(n + 1, true);
    isPrime[0] = false;
    if (n >= 1) isPrime[1] = false;
    for (long long p = 2; p * p <= n; p++) {
        if (!isPrime[p]) continue;                  // p is crossed out, skip it
        for (long long x = p * p; x <= n; x += p)
            isPrime[x] = false;                     // cross out the multiples of p
    }
    for (int x = 2; x <= n; x++)
        if (isPrime[x]) cout << x << " ";
    cout << "\n";
}

The sieve needs an array of size \( n \). So it helps only for values up to about \( 10^7 \). For one big number like \( 10^{12} \), use Part C.

Change it to fit

The default tools are gcd from C++ and the loop with i * i <= n. Small changes fit many problems.

  • You need how many divisors, not the list. Count instead of storing. For 36 you get 9. 
    
if (n % i == 0) cnt += (i == n / i) ? 1 : 2;   // a pair gives 2, the middle (6 * 6) gives 1
  • You need the GCD of a whole array. Start with 0, because gcd(0, x) is x. For 12, 18, 30 you get 6. 
    
long long g = 0;
for (long long x : a) g = gcd(g, x);
  • You need the LCM of a whole array. It grows very fast and can overflow. Check before you multiply. Here LIMIT is the biggest value you care about, like \( 10^{18} \). 
    
long long l = 1;
for (long long x : a) {
    long long step = l / gcd(l, x);          // l * x / gcd, divided first
    if (step > LIMIT / x) { tooBig = true; break; }
    l = step * x;
}
  • You need to factorise many numbers. Change one line of the sieve. Keep the smallest prime that divides each number, not only true or false. The details are in "Not now".

Solve one together

Problem. You get two numbers \( a \) and \( b \). How many numbers divide both of them? Limits: \( 1 \le a, b \le 10^{12} \).

  1. What is asked? The number of common divisors of \( a \) and \( b \).
  2. A small example by hand. Take \( a = 12 \) and \( b = 18 \).
    divisors of 121234612
    divisors of 181236918

    The common ones are 1, 2, 3, 6. The answer is 4.

  3. The idea. Look at the common divisors 1, 2, 3, 6. They are exactly the divisors of 6, and \( \gcd(12, 18) = 6 \). The common divisors of \( a \) and \( b \) are exactly the divisors of \( \gcd(a, b) \). So: find \( g = \gcd(a, b) \) with Part A. Then count the divisors of \( g \) with the change "how many divisors".
  4. Why is it fast enough? gcd takes fewer than 100 steps. The number \( g \) is at most \( 10^{12} \). The loop with i * i <= g makes at most \( 10^6 \) steps. That is far below \( 10^8 \).

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    long long g = gcd(a, b);                    // the common divisors = the divisors of g
    long long cnt = 0;
    for (long long i = 1; i * i <= g; i++) {    // i is long long: i * i can pass 2 * 10^9
        if (g % i == 0) cnt += (i == g / i) ? 1 : 2;
    }
    cout << cnt << "\n";
}

Speed: gcd is \( O(\log n) \). Divisors, prime test and factorisation are \( O(\sqrt{n}) \): fine for one \( n \) up to \( 10^{12} \). The sieve is almost \( O(n) \): fine for \( n = 10^7 \).

Wrong ideas people get

  • You may think: To test if n is prime, I must try every number up to n.

    The truth: Trying up to the square root is enough. Every big divisor has a small partner. For \( 10^{12} \) that is \( 10^6 \) steps, not \( 10^{12} \).

  • You may think: The sieve is always the fastest way to find primes.

    The truth: The sieve needs an array of size n. It does not work for one number up to \( 10^{12} \). Use it for many numbers up to about \( 10^7 \).

  • You may think: 1 is a prime.

    The truth: 1 is not a prime. The smallest prime is 2. That is why isPrime returns false for \( n < 2 \).

Common mistakes

  • int i in i * i <= n. For \( n \) near \( 2 \cdot 10^9 \) or bigger, i * i overflows. Make i a long long.
  • LCM as a * b / g. The product can overflow. Write a / g * b.
  • Counting the middle divisor twice. For 36, the pair \( 6 \cdot 6 \) is one divisor, not two.

Not now

  • The smallest-prime-factor sieve. It factorises many numbers very fast. Below 1600 the loop of Part D is almost always enough. Come back after the guide: After 1600.
  • Division with remainders (the modular inverse). You meet it in Counting with nCr.
  • Fast prime tests for numbers near \( 10^{18} \). They are rare below 1600. Come back after the guide: After 1600.

Check yourself

  1. \( n = 10^{12} + 39 \) is a prime. About how many steps does isPrime make?
    Answer

    About \( 10^6 \). The loop runs while \( i \cdot i \le n \), so \( i \) goes up to about \( \sqrt{10^{12}} = 10^6 \).

  2. What is \( \gcd(24, 36) \)? Write the steps of Euclid.
    Answer

    \( (24, 36) \to (36, 24) \to (24, 12) \to (12, 0) \). The answer is 12.

  3. You must answer "is x prime?" for \( 10^5 \) numbers, each up to \( 10^6 \). Which part do you use?
    Answer

    Part E. Build one sieve up to \( 10^6 \). Then each question is one look into the array. Part C for each number would cost up to \( 10^5 \cdot 10^3 = 10^8 \) steps.
