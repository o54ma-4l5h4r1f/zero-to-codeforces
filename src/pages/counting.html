Count how many times each value appears. Then answer from the counts, not from the long array.

Before this lesson

  • You can loop over a string and use c - 'a' → Arrays and strings
  • You can use a map → map, set, stack, queue
  • You know when to use long long → int or long long?

Spot it

  • "How many times…", "the most common…", "appears exactly once", "all letters are used".
  • Only the frequency of each value matters, not its position.
  • "Count the pairs \( (i, j) \) with \( i < j \) and …", and \( n \) is up to \( 2 \cdot 10^5 \). You cannot try all pairs.

Three ways to understand it

1 · Story — counting votes

People vote for a class leader. You do not keep the papers in a long line. You write each name on the board once. For each paper, you add one mark next to its name.

At the end you read the board. Who has the most marks? Who has zero? The board answers fast.

2 · Picture — count the letters of "cabbage"

One box for each letter. Letter c goes to box c - 'a'. So cnt[0] is 'a', cnt[1] is 'b', … cnt[6] is 'g'. The code has 26 boxes; the picture shows the first 7.

3 · Code — small values: array, big values: map


string s;
cin >> s;
int cnt[26] = {0};                     // one box for each letter a..z
for (char c : s) cnt[c - 'a']++;
int kinds = 0;
for (int i = 0; i < 26; i++)
    if (cnt[i] > 0) kinds++;           // number of distinct letters

Numbers up to \( 10^9 \)? An array with \( 10^9 \) boxes needs 4 GB. Use a map: it keeps a box only for values that appear.


map<int, int> cnt;                    // cnt[x] = how many times x appears
for (int x : a) cnt[x]++;
for (auto [value, times] : cnt)        // values come sorted
    cout << value << " appears " << times << " times\n";

Which one do I use? Values between 0 and \( 10^6 \): an array. Bigger, negative, or strings: a map.

Solve one together

Problem. You get an array \( a_0, a_1, \dots, a_{n-1} \). Count the pairs \( i < j \) with \( a_j - a_i = j - i \). Limits: \( 1 \le n \le 2 \cdot 10^5 \) and \( 1 \le a_i \le n \). There are up to \( 10^4 \) tests; the sum of all \( n \) is at most \( 2 \cdot 10^5 \).

  1. What is asked? One number per test: how many pairs fit the rule.
  2. A small example by hand. Take a = 3 2 5 6 5 7. The pair \( (0, 3) \) fits: \( 6 - 3 = 3 \) and \( 3 - 0 = 3 \). Checking every pair works here: 15 pairs. For \( n = 2 \cdot 10^5 \) it is \( 2 \cdot 10^{10} \) pairs. Too slow.
  3. The idea. Move everything with \( i \) to one side: \( a_j - j = a_i - i \). Now make \( b_i = a_i - i \).
    i012345
    a[i]325657
    b[i] = a[i] − i313312

    Now we count pairs of equal values in b. For each element, ask: how many earlier ones are equal to me? The count array knows the answer.

    A short formula. The value 3 appears 3 times. It gave \( 0 + 1 + 2 = 3 \) pairs. A value that appears \( k \) times gives \( 0 + 1 + \dots + (k - 1) \) pairs:

    \[ \frac{k (k - 1)}{2} \text{, so for } k = 3: \frac{3 \cdot 2}{2} = 3 \]

    Both ways give the same answer. Use the one-pass loop: it needs no second loop.

    In the real input \( a_i - i \) can be negative, for example \( 2 - 5 = -3 \). So the program uses a map.

  4. Why is it fast enough? One pass with a map: about \( 2 \cdot 10^5 \cdot 18 \approx 3.6 \cdot 10^6 \) steps. The answer can be about \( 2 \cdot 10^{10} \), so it needs long long.

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        map<int, int> cnt;                 // new and empty for every test
        long long pairs = 0;               // can be about n * n / 2
        for (int j = 0; j < n; j++) {
            int a;
            cin >> a;
            int b = a - j;                 // b[j] = a[j] - j
            pairs += cnt[b];               // every earlier equal b makes a pair
            cnt[b]++;                      // now this one is "earlier" too
        }
        cout << pairs << "\n";
    }
}

Speed: \( O(n) \) with an array, \( O(n \log n) \) with a map. Both are fine for \( n = 2 \cdot 10^5 \).

Wrong ideas people get

  • You may think: To count pairs I need two loops, over i and over j.

    The truth: One pass is enough: for each element, add how many equal ones came before it.

  • You may think: A count array works for any values.

    The truth: The index must be between 0 and the size minus 1. Big or negative values need a map.

  • You may think: \( n \) fits in int, so the number of pairs fits too.

    The truth: With \( n = 2 \cdot 10^5 \) there can be \( 2 \cdot 10^{10} \) pairs. That is more than int holds. Use long long.

Common mistakes

  • Many test cases: you forget to clear the counts. Make the map inside the test loop, as above.
  • A big count array cleared in every test. With \( 10^4 \) tests that is too slow. Clear only the boxes you used.
  • cnt[c] for a letter, with 26 boxes. Write cnt[c - 'a']. Capital letters need c - 'A'.

Not now

  • Groups of 3 or more equal values and other "how many ways" formulas: Combinatorics.
  • Remainders of negative numbers. In C++, -7 % 3 is -1. The fix is in Mod and fast power.
  • Faster maps with hashing. A map is fast enough below 1600: After 1600.

Check yourself

  1. You count the word aabbbc. What is cnt[1]?
    Answer

    3. Box 1 is the letter 'b', and 'b' appears 3 times.

  2. The array is 5 5 5 5. How many pairs \( i < j \) have a[i] == a[j]?
    Answer

    6. One pass adds \( 0 + 1 + 2 + 3 = 6 \). The formula gives \( \frac{4 \cdot 3}{2} = 6 \).

  3. The values go up to \( 10^9 \) and \( n = 2 \cdot 10^5 \). Array or map?
    Answer

    A map. An array would need \( 10^9 \) boxes. The map keeps at most \( 2 \cdot 10^5 \).
