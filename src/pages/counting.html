Count how many times each value appears. Then answer from the counts, not from the long array.

Spot it

  • "How many times…", "the most common…", "appears exactly once", "all letters are used".
  • Only the frequency of each value matters, not its position.
  • "Count the pairs (i, j) with i < j and …" and n is up to 200 000. You cannot try all pairs.
  • The values are small (letters, numbers up to 106) → array. The values are big (up to 109) → map.

Three ways to understand it

1 · Story — counting votes

People vote for a class leader. You do not keep the papers in a long line. You make one row for each name on the board. For each paper you add one mark to its row.

At the end you read the board. Who has the most marks? Who has zero? The board answers fast.

2 · Picture — count the letters of "banana"

One box for each letter. Letter c goes to box c - 'a': 'a' → 0, 'b' → 1, … 'n' → 13.

Now it is easy: 3 distinct letters, the most common is 'a', and 'b' appears exactly once.

3 · Code — small values: array, big values: map


string s;
cin >> s;
int cnt[26] = {0};                     // one box for each letter a..z
for (char c : s) cnt[c - 'a']++;
int kinds = 0;
for (int i = 0; i < 26; i++)
    if (cnt[i] > 0) kinds++;           // number of distinct letters

Counting pairs. Task: how many pairs i < j have a[i] == a[j]? Walk from left to right. For each element ask: "how many earlier elements are equal to me?" The map knows.


#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    map<int, int> cnt;                 // cnt[x] = how many x we saw before
    long long pairs = 0;               // can be about n*n/2 -> long long
    for (int j = 0; j < n; j++) {
        int x;
        cin >> x;
        pairs += cnt[x];               // every earlier x makes a pair with this one
        cnt[x]++;                      // now this one is "earlier" too
    }
    cout << pairs << "\n";
}

Another way to the same answer: k equal items make k · (k − 1) / 2 pairs. Add this for every value.


long long pairs = 0;
for (auto [value, k] : cnt)
    pairs += 1LL * k * (k - 1) / 2;    // 1LL makes the product long long

Trick: move everything with i to one side. "Count pairs with a[j] − a[i] = j − i" is the same as a[j] − j = a[i] − i. So make b[i] = a[i] − i and count pairs of equal values in b.

Speed: O(n) with an array, O(n log n) with a map. Both are fine for n = 200 000.

Common mistakes

  • The number of pairs in an int. With n = 200 000 it can be 2·1010. Use long long.
  • An array cnt[x] when x can be 109. That is too much memory. Use a map.
  • Many test cases: you forget to clear the counts, or you clear a huge array in every test (too slow). Clear only the part you used.
  • Writing cnt[c] for a letter when the array has 26 boxes. Write cnt[c - 'a'].
