== pocket | s4 | Which tool? Pocket version
-- choose-a-tool | The routine for every problem, from the end of the page "Which tool?". Do the steps in this order.
1. Limits → allowed cost ($$: 10^8$$ steps per second).
2. The task in one sentence.
3. Samples by hand.
4. Kind of answer: yes/no, count, min/max, build, queries.
5. Brute force and its cost. Fits? Code it.
6. Too slow? What is repeated? Remove it with a tool.
7. Edge cases and {{: long long}}, then submit.
-- choose-a-tool span2 | 12 strong signals in a statement and the tool each one points to. The page "Which tool?" explains each one.
$$: n \le 20$$ → try all subsets (mask).
$$: n \le 5000$$ → $$: O(n^2)$$ is fine.
$$: n \le 2 \cdot 10^5$$ → sort, one loop, $$: O(n \log n)$$.
Values up to $$: 10^{12}$$ → $$: \sqrt{n}$$ loop; up to $$: 10^{18}$$ → formula or $$: \log$$; {{: long long}}.
Many "sum l..r" queries → prefix sums.
Longest window with sum $$: \le S$$ → two pointers.
"Min value that works", monotonic → binary search on the answer.
Only frequencies matter → counting.
Order does not matter → sort first.
"Modulo $$: 10^9+7$$", count ways → DP or C(n, k).
Fewest moves, equal cost → BFS; weights → Dijkstra.
"Print any" → constructive: solve tiny $$: n$$ by hand.

== division | s2 | Division and rounding
-- basic-math | Division of two integers cuts the fraction: it rounds toward zero. The remainder has the sign of the left number. Never divide by 0.
{{d1: 7 / 2}} is {{: 3}} · {{d2: -7 / 2}} is {{: -3}}
{{d3: 7 % 2}} is {{: 1}} · {{d4: -7 % 2}} is {{: -1}}
always true: {{dident: a == (a / b) * b + a % b}}
-- basic-math | Round a / b down, up, or to the nearest integer. Only for a >= 0 and b > 0. A half rounds up.
down: $$: \lfloor a / b \rfloor$$ = {{floorpos: a / b}}
up: $$: \lceil a / b \rceil$$ = {{ceilpos: (a + b - 1) / b}}
up, no overflow: {{ceilpos2: a / b + (a % b != 0)}}
nearest: {{roundpos: (a + b / 2) / b}}
-- basic-math | Round down and round up when a or b can be negative. C++ rounds toward zero, so one step of repair is needed. b must not be 0.
>>> global floorceil
long long floorDiv(long long a, long long b) {
    long long q = a / b;
    if (a % b != 0 && (a < 0) != (b < 0)) q--;
    return q;
}
long long ceilDiv(long long a, long long b) {
    long long q = a / b;
    if (a % b != 0 && (a < 0) == (b < 0)) q++;
    return q;
}
<<<
